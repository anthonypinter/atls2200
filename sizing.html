Sizing Items

Without a set size, a block fills the width it's given and is as tall as its content. Set sizes with care: fixed pixels break on small screens, while percentages and min/max limits adapt.

Part 3

aspect-ratio and viewport units

Key ideas

  • width: 100%; max-width: 600px; is the go-to pattern: full width on phones, capped on big screens.
  • Percentage widths are a share of the parent's width.
  • Let height come from the content. Reach for min-height if you need a minimum.
  • aspect-ratio keeps a box's shape as its width changes, great for video and image placeholders.
  • vh is a percentage of the browser window's height. 100vh is the full screen.

Common mistakes

  • Big fixed widths like width: 1000px that overflow on phones.
  • A percentage height that does nothing because the parent has no set height.
  • Fixed heights on text boxes, so text spills out.
  • Using 100vh on phones, where browser toolbars make it slightly too tall. 100dvh adjusts for them.
