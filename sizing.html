Sizing Items

Without a set size, a block fills the width it's given and is as tall as its content. Set sizes with care: fixed pixels break on small screens, while percentages and min/max limits adapt.

You'll be able to

  • Size boxes with fixed, percentage and max-width values that adapt to the screen.
  • Choose min-height over height for boxes that hold text.
  • Keep a box's shape with aspect-ratio, and size by the screen with vh.
Read

Sizes that adapt

Left alone, a block element is as wide as its parent and as tall as its content. That default is usually right, and most sizing bugs start when you override it with fixed numbers.

A box with width: 1000px is 1000px wide on a laptop and on a phone that's only 390px wide, so it sticks out and the whole page scrolls sideways. The pattern you'll use constantly is this one:

.content {
  width: 100%;
  max-width: 600px;
}

On a phone the box fills the screen. On a big screen it stops growing at 600px, which keeps lines of text short enough to read comfortably. min-width works the other way, setting a floor.

Percentages are a share of the parent's width, so width: 50% is half of whatever contains it. Percentage heights are trickier: they only work if the parent has a set height, which it usually doesn't.

Height deserves extra care. Text wraps onto more lines as the screen narrows, so a box with a fixed height eventually can't hold its text, and the text spills out. If you need a box to be at least a certain height, use min-height, which lets it grow.

Two more tools help. aspect-ratio: 16 / 9 keeps a box's shape as its width changes, which is perfect for video and image placeholders. And vh is a percentage of the window's height, so min-height: 100vh fills the screen. On phones, where toolbars come and go, 100dvh adjusts for them.

Tip

Before setting any width or height, ask whether the content could decide instead. Fewer fixed sizes means fewer layouts that break on someone else's screen.

Key ideas

  • width: 100%; max-width: 600px; is the go-to pattern: full width on phones, capped on big screens.
  • Percentage widths are a share of the parent's width.
  • Let height come from the content. Reach for min-height if you need a minimum.
  • aspect-ratio keeps a box's shape as its width changes, great for video and image placeholders.
  • vh is a percentage of the browser window's height. 100vh is the full screen.

Common mistakes

  • Big fixed widths like width: 1000px that overflow on phones.
  • A percentage height that does nothing because the parent has no set height.
  • Fixed heights on text boxes, so text spills out.
  • Using 100vh on phones, where browser toolbars make it slightly too tall. 100dvh adjusts for them.
