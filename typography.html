Read

Text people can read

Most of what's on a web page is text, so the way it reads matters more than almost any other design choice. A few settings make most of the difference:

body {
  font-family: "Source Sans 3", Arial, sans-serif;
  font-size: 1.125rem;
  line-height: 1.6;
}
p {
  max-width: 65ch;
}

font-family takes a font stack: a list of fonts in order of preference. If the first isn't available, the browser tries the next. Always end with a generic family like sans-serif or serif, so there's a sensible fallback font no matter what. Put quotes around names with spaces.

For body text, aim for at least 16px, which is 1rem, and a line-height between about 1.4 and 1.8. Write the line height without a unit, so it scales with the text size.

Line length is the setting people forget. Lines that run the full width of a big monitor make readers lose their place jumping back to the start of the next line. About 45 to 75 characters per line reads best, and the ch unit, roughly the width of one character, makes that easy: max-width: 65ch.

For headings, pick sizes that belong together. A type scale multiplies each level by the same ratio: with a 16px base and a ratio of 1.25, you get 20, 25, 31 and 39px. The sizes feel related instead of random.

Tip

Use two typefaces at most, one for headings and one for body text. Left-align long paragraphs: centered text is fine for a short heading, but hard to read for more than a line or two.

Why the trail closes in spring

Every April, the lower section of the Mesa Trail closes for about six weeks. Snowmelt turns the clay soil into deep mud, and hikers who step around the puddles widen the trail and trample the wildflowers growing at its edges.

Rangers reopen the trail once the ground can hold a footprint without sinking. Until then, the upper loop stays open and drains much faster.

    Practice

    Make it readable

    The text is set in one long, cramped line. Fix the font, the spacing and the line length.

    Key ideas

    • Aim for 45 to 75 characters per line. Set max-width in ch on paragraphs.
    • Body text reads best with a line-height between about 1.4 and 1.8, and no unit.
    • Always end a font-family list with a generic fallback like sans-serif or serif.
    • Use two typefaces at most: one for headings, one for body text.

    Common mistakes

    • Lines stretching the full width of a big monitor, so readers lose their place.
    • Centering long paragraphs. Center short headings only.
    • Body text under 16px, which is hard to read on phones.
    • Font names with spaces but no quotes, or a Google Font used without its <link> tag.
