Loops

A loop runs the same code again and again, usually once for each item in a list. Step through each kind of loop to see exactly what runs, and in what order.

    Part 2

    map() and filter()

    Arrays have methods that do the looping for you. You pass in a small function, and the method calls it once for each item.

    Key ideas
    
      
      
        
    • for...of is the simplest way to go through every item: for (const trail of trails) { … }. Use it when you don't need the index.
      • 
        
    • A classic for loop has three parts: (initializer; condition; final-expression). Use it when you need to count, or need the index.
      • 
        
    • while repeats as long as its condition is true. Good when you don't know in advance how many times to repeat.
      • 
        
    • map() makes a new array of changed items. filter() makes a new array of only the items that pass a test.
      • 
        
    • querySelectorAll() results work with for...of too. That's how you add a listener to every button on a page.
      • 
      
    
    
    
    
    
      
    Common mistakes
    
      
      
        
    • i <= arr.length runs one time too many and reads undefined. Use <.
      • 
        
    • Forgetting to change the counter in a while loop. The condition never becomes false, and the page freezes.
      • 
        
    • Using const for a classic loop counter: for (const i = 0; …; i++) fails because i++ reassigns it. (const is fine in for...of.)
      • 
        
    • Forgetting to return in a map() function that uses curly braces, which gives an array of undefined.
