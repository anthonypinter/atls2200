What you've covered

This part was the JavaScript language itself: storing values, making decisions, repeating work and packaging it into functions. None of it touches the page yet; that's the next part.

  • What Is JavaScript?: JavaScript adds behavior; link it with a script tag and defer.
  • The Console & Errors: The console shows errors with a line number. Fix the first one first.
  • Variables & Data Types: const by default, let when the value changes.
  • Numbers & Strings: + joins if either side is a string; convert form values with Number().
  • Arrays: Arrays are ordered lists indexed from 0, with methods to add and remove items.
  • Conditionals: if runs the first true branch only, so put specific conditions first, and compare with ===.
  • Loops: for...of visits every item; a total starts at 0 and grows inside the loop.
  • Functions: Parameters take values in, return sends one back, and scope keeps variables local.
  • Objects & JSON: Objects group values under keys; JSON.parse and JSON.stringify convert to and from text.
