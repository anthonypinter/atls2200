Backgrounds & Borders

Backgrounds can be a color, a gradient, an image, or several layered together. Borders frame a box and border-radius rounds its corners. Build a trail card from the pieces.

You'll be able to

  • Use colors, gradients and images as backgrounds, and layer them.
  • Control a background image with size, position and repeat.
  • Add borders and round corners with border-radius.

Fill and frame a box

A box's background can be a solid color, a gradient, an image, or several of those stacked together. A gradient counts as an image, so it goes in background-image, not background-color.

Layering is the trick behind a classic look: white text on a photo, with a dark gradient over the photo so the text stays readable.

.hero {
  background-image:
    linear-gradient(rgb(0 0 0 / 60%), transparent),
    url("../img/flatirons.jpg");
  background-size: cover;
  background-position: center;
  color: white;
}

Layers are separated by commas, and the first one is drawn on top. background-size: cover scales the image to fill the box, cropping as needed, and background-position chooses which part stays in view. The path inside url() starts from the CSS file's folder, not the page's.

A border needs three things: a width, a style and a color, as in border: 2px solid #2340d9. Leave out the style and nothing appears, because the default style is none. border-radius rounds the corners: 10px for a gentle curve, and 50% on a square for a perfect circle.

Watch out

A background image never appears on an element with no height. Backgrounds fill the box, so an empty div with a background is invisible until you give it content, padding or a height.

Key ideas

  • Gradients are images, so they go in background-image (or the background shorthand), not background-color.
  • Layer backgrounds with commas. The first one listed is drawn on top.
  • A dark gradient over a photo keeps white text readable.
  • border-radius: 50% on a square makes a circle.
  • Background image paths in CSS start from the CSS file's folder.

Common mistakes

  • A background image that never shows because the element has no height.
  • Using a background image for content that matters. Screen readers can't see it and it has no alt text.
  • White text on a busy photo with no overlay.
  • Setting border-width without border-style. The default style is none, so nothing appears.
