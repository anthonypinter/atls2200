Backgrounds & Borders

Backgrounds can be a color, a gradient, an image, or several layered together. Borders frame a box and border-radius rounds its corners. Build a trail card from the pieces.

Key ideas

  • Gradients are images, so they go in background-image (or the background shorthand), not background-color.
  • Layer backgrounds with commas. The first one listed is drawn on top.
  • A dark gradient over a photo keeps white text readable.
  • border-radius: 50% on a square makes a circle.
  • Background image paths in CSS start from the CSS file's folder.

Common mistakes

  • A background image that never shows because the element has no height.
  • Using a background image for content that matters. Screen readers can't see it and it has no alt text.
  • White text on a busy photo with no overlay.
  • Setting border-width without border-style. The default style is none, so nothing appears.
