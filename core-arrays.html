Arrays

When you have a list of related values, like every trail in a guide, an array keeps them in order under one name. You can read any item, add and remove items, loop through them all, and convert between arrays and strings.

You'll be able to

  • Create arrays, read their length, and read or change items by index.
  • Add and remove items with push, pop, unshift, shift and splice.
  • Do something with every item using for...of, map() and filter().
  • Convert between strings and arrays with split() and join().

What is an array?

An array is a single variable that stores a list of values, in order. Instead of trail1, trail2, trail3, you have one trails list that can hold three items or three thousand, and code that works the same either way.

Accessing and modifying array items

Each item has an index, its position, counted from 0. So the first item is trails[0] and the last is trails[trails.length - 1]. Asking for an index that doesn't exist gives undefined, not an error. To change an item, assign to its index: trails[1] = "Flagstaff". For an array inside an array, use two indexes: nested[1][0].

Finding the index of items in an array

indexOf("Royal Arch") returns an item's position, or -1 if it isn't in the array. includes("Mesa") just answers true or false.

Read

Adding items

push() adds one or more items to the end; unshift() adds them to the start. Both change the array, and return its new length.

Read

Removing items

pop() removes the last item and shift() removes the first; both return the item they removed. To remove from the middle, find the index and use splice(index, howMany):

const index = trails.indexOf("Royal Arch");
if (index !== -1) {
  trails.splice(index, 1);   // remove 1 item at that index
}

Some methods change the array itself (push, pop, splice); others leave it alone and hand you an answer (includes, indexOf, slice, join). Knowing which kind you're using saves a lot of confusion.

Converting between strings and arrays

  


split() breaks a string into an array at a separator. join() does the opposite, joining items with a separator you choose. (toString() also joins, but always with commas.)

Key ideas

      
    
        
  • An array is an ordered list under one name: ["Mesa", "Royal Arch"]. length is how many items.
    • 
        
  • Indexes start at 0; the last item is at length - 1. indexOf() returns -1 when not found.
    • 
        
  • push/pop work at the end, unshift/shift at the start, splice in the middle.
    • 
        
  • for...of visits every item; map() transforms them; filter() keeps some.
    • 
        
  • split() turns a string into an array; join() turns an array into a string.
    • 
      

    

    

      
Common mistakes

      
    
        
  • Reading trails[trails.length] for the last item. It's length - 1.
    • 
        
  • Expecting slice() or map() to change the original array.
    • 
        
  • Calling splice(index, 1) when indexOf returned -1, which removes the last item.
    • 
        
  • Forgetting that a const array can still be changed with push and pop.
