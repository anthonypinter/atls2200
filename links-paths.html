Links & Paths

A relative path is directions from the file you're writing in to the file you want. Pick where you are, click where you want to go, then try writing the path yourself.

    How to read it
      Reference

      Kinds of links

      Relative path

      images/logo.png../about.html

      Starts from the current file's folder. Use this for files in your own site.

      Absolute URL

      https://developer.mozilla.org

      The full address. Use it for other websites.

      Root-relative

      /images/logo.png

      Starts at the top of the domain. Breaks on GitHub Pages project sites and when opening files directly, so avoid it in this class.

      Same-page anchor

      #contact

      Jumps to the element with id="contact" on this page.

      Email

      mailto:you@example.com

      Opens the visitor's email app, if they have one set up.

      Key ideas

      • ../ means "go up one folder." Use it once per level you need to climb.
      • A path in a CSS file, like url(...), starts from the CSS file's folder, not the HTML page's.
      • Link text should say where the link goes. "Read the trail guide" beats "click here."
      • Opening a link in a new tab with target="_blank" is fine for outside sites, but don't do it for every link.

      Common mistakes

      • Wrong capitalization: Trail-Photo.jpg isn't Trail-Photo.JPG. Your laptop may forgive it, but web servers usually won't.
      • Spaces in file names, which turn into %20 and break easily. Use dashes.
      • Paths from your own computer, like C:\Users\... or file:///. They only work on your machine.
      • Backslashes. Web paths always use forward slashes /.
