Links & Paths

A relative path is directions from the file you're writing in to the file you want. Pick where you are, click where you want to go, then try writing the path yourself.

You'll be able to

  • Write a relative path from one file to another, including ../ to go up a folder.
  • Choose between relative, root-relative and absolute links.
  • Write link text that says where the link goes.
Read

Directions from here to there

Every link has an href that says where it goes. Links to other sites use an absolute path, the full address: https://www.nps.gov/romo/. Links between your own files use a relative path, which is directions from the file you're writing in to the file you want.

Picture this project:

trail-club/
├── index.html
├── about.html
├── css/
│   └── style.css
└── hikes/
    ├── mesa.html
    └── photos/
        └── mesa.jpg

From index.html, the path to the Mesa page is hikes/mesa.html: into the hikes folder, then the file. From mesa.html, the photo is photos/mesa.jpg. And from mesa.html back to the home page is ../index.html. The ../ means "go up one folder", and you use it once for each level you need to climb.

Two details catch everyone. A path inside a CSS file, like url(...), starts from the CSS file's folder, not the page's. And web paths always use forward slashes and are case-sensitive once they're online.

Finally, make the link text say where it goes. "Read the Mesa Trail guide" tells a screen reader user, who may be skimming a list of every link on the page, exactly what they'll get. "Click here" tells them nothing.

Watch out

A path like C:\Users\you\Desktop\mesa.jpg or file:///… points at your own computer. It works for you and for nobody else, so the image breaks as soon as the site is online.

      Reference

      Kinds of links

      Relative path

      images/logo.png../about.html

      Starts from the current file's folder. Use this for files in your own site.

      Absolute URL

      https://developer.mozilla.org

      The full address. Use it for other websites.

      Root-relative

      /images/logo.png

      Starts at the top of the domain. Breaks on GitHub Pages project sites and when opening files directly, so avoid it in this class.

      Same-page anchor

      #contact

      Jumps to the element with id="contact" on this page.

      Email

      mailto:you@example.com

      Opens the visitor's email app, if they have one set up.

      Practice

      Fix the paths

      This page lives in a subfolder, so each link needs a path that starts from there.

      Key ideas

      • ../ means "go up one folder." Use it once per level you need to climb.
      • A path in a CSS file, like url(...), starts from the CSS file's folder, not the HTML page's.
      • Link text should say where the link goes. "Read the trail guide" beats "click here."
      • Opening a link in a new tab with target="_blank" is fine for outside sites, but don't do it for every link.

      Common mistakes

      • Wrong capitalization: Trail-Photo.jpg isn't Trail-Photo.JPG. Your laptop may forgive it, but web servers usually won't.
      • Spaces in file names, which turn into %20 and break easily. Use dashes.
      • Paths from your own computer, like C:\Users\... or file:///. They only work on your machine.
      • Backslashes. Web paths always use forward slashes /.
