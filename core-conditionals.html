Conditionals

Programs make choices: show the error or don't, say good morning or good evening, pick a color theme. Conditionals run code only when something is true.

You'll be able to

  • Write if, else if and else chains, in the right order.
  • Use truthy and falsy values, and combine conditions with &&, || and !.
  • Match one value against many cases with switch.
  • Choose between two values with the ternary operator.

if...else statements

Basic if...else syntax

A conditional runs a block of code only if a condition is true, and (optionally) a different block if it isn't:

if (condition) {
  // runs if the condition is true
} else {
  // runs otherwise
}

A real example

MDN's example: a child is asked to help their parent. If they did the shopping, they get pocket money; if not, they don't.

else if

For more than two choices, chain else ifs. JavaScript checks each condition from top to bottom, runs the first block whose condition is true, then skips everything else, even if later conditions would also be true. So order matters: put the most specific conditions first.

if (temp >= 85) {
  msg = "Hike early. It'll be hot.";
} else if (temp >= 50) {
  msg = "Perfect hiking weather.";
} else {
  msg = "Bring layers.";
}

A note on comparison operators

Compare with <, >, <=, >=, === and !==. Always use three equals signs.

A condition doesn't have to be a comparison: any value works. Six values count as false: false, 0, "", null, undefined and NaN. These are called falsy, and everything else is truthy. So if (name) checks whether someone typed anything.

Watch out

if (x = 5) doesn't compare. It sets x to 5, and since 5 is truthy, the block always runs.

Logical operators: AND, OR and NOT

    
Often you can avoid nesting by combining conditions:

    
    
      
  • && (AND): true only if both sides are true. if (choice === "sunny" && temperature < 86)
    • 
      
  • || (OR): true if at least one side is true.
    • 
      
  • ! (NOT): flips true and false. if (!isRaining)
    • 
    

    
A classic mistake: if (x === 5 || 7) doesn't mean "x is 5 or 7". It means "x is 5, or 7 is truthy", and 7 is always truthy, so it always runs. Write both comparisons in full: if (x === 5 || x === 7).

When you're checking one value against lots of exact matches, a long else if chain gets repetitive. A switch statement is tidier:

Each case is one possible value. When one matches, its code runs until break. If you leave out break, it carries on into the next case, which is handy for grouping (Saturday and Sunday below) but a bug if you forget. default runs if nothing matches.

Ternary operator

  


The ternary operator is a one-line if...else that produces a value: condition ? valueIfTrue : valueIfFalse. It's ideal for picking between two things, like two greetings or two themes:

    
Ternary operator example

    
const greeting = isBirthday
  ? "Happy birthday Mrs. Smith — we hope you have a great day!"
  : "Good morning Mrs. Smith.";

Key ideas

      
    
        
  • if / else if / else runs the first block whose condition is true, then stops checking.
    • 
        
  • Compare with === and !==. Falsy values: false, 0, "", null, undefined, NaN.
    • 
        
  • && needs both, || needs either, ! flips.
    • 
        
  • switch matches one value against exact cases; don't forget break.
    • 
        
  • condition ? a : b picks a value in one line.
    • 
      

    

    

      
Common mistakes

      
    
        
  • if (x = 5): one equals sign assigns instead of comparing.
    • 
        
  • x === 5 || 7, which is always true. Write x === 5 || x === 7.
    • 
        
  • Putting a general condition (>= 50) before a specific one (>= 85), so the specific one never runs.
    • 
        
  • Forgetting break in a switch, so the next case runs too.
