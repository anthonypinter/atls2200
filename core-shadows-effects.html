Shadows and Effects

Shadows add depth, filters change how an element is drawn, and blend modes mix layers like a photo editor. Used lightly, they give a page polish; overdone, they make it hard to read.

You'll be able to

  • Add soft, layered and inset box shadows, and text shadows that keep text readable.
  • Apply filters like blur(), grayscale() and drop-shadow().
  • Mix layers with background-blend-mode and mix-blend-mode.
  • Wrap text around a shape, and fill text with a gradient.

Box shadows

A simple box shadow

box-shadow takes up to five values: horizontal offset, vertical offset, blur, spread, and a colour.

.simple {
  box-shadow: 5px 5px 5px rgb(0 0 0 / 70%);
}

The best shadows are barely noticeable. Use a semi-transparent colour rather than solid black, and let it fall slightly downward, as if lit from above. A shadow is painted, not laid out: it takes no space and never pushes other boxes away.

Multiple box shadows

Separate several shadows with commas. Stacking a tight, darker one with a wide, faint one looks much more natural than either alone:

.card {
  box-shadow:
    0 1px 2px rgb(0 0 0 / 12%),
    0 8px 24px rgb(0 0 0 / 10%);
}

Other box shadow features

The inset keyword draws the shadow inside the box, which makes it look pressed in. Swapping an outer shadow for an inset one on :active is a classic "pressed button" effect.

Filters

The filter property changes how an element is drawn, like a photo editor: blur(10px), grayscale(60%), brightness(), contrast(), invert(), hue-rotate(), sepia(). It applies to the whole element, text and children included.

filter: drop-shadow() is a shadow that follows the element's actual shape, including transparent areas of an image, where box-shadow always follows the rectangle.

Blend modes

Blend modes decide how overlapping colours mix, as in Photoshop: multiply darkens, screen lightens, overlay boosts contrast, difference inverts.

background-blend-mode

Blends an element's own background layers together, like a background image with its background colour: background-blend-mode: multiply tints the image with the colour.

mix-blend-mode

Blends a whole element with whatever is behind it on the page.

CSS shapes

  


Text normally wraps around a floated element's rectangle. shape-outside makes it wrap around a shape instead, such as a circle:

    
img {
  float: left;
  shape-outside: circle(50%);
}

-webkit-background-clip: text

  


background-clip decides how far a background reaches. Its text value clips the background to the letters, so a gradient or image fills the text. Make the text itself transparent to see it:

    
h2 {
  background-image: linear-gradient(90deg, #0b6b5e, #2340d9, #b4410c);
  -webkit-background-clip: text;
  background-clip: text;
  -webkit-text-fill-color: transparent;
}

    
The -webkit- prefix is a vendor prefix: a browser-specific version from before the feature was standardised. Some browsers still need it here, so write both. Check that the text stays readable, and that a colour shows if the effect isn't supported.

Key ideas

      
    
        
  • box-shadow: x, y, blur, spread, colour; stack several with commas.
    • 
        
  • Shadows take no space; inset draws them inside.
    • 
        
  • filter edits how a whole element is drawn; drop-shadow() follows its shape.
    • 
        
  • background-blend-mode mixes an element's own layers; mix-blend-mode mixes it with the page.
    • 
        
  • background-clip: text fills letters with a background; keep a readable fallback.
    • 
      

    

    

      
Common mistakes

      
    
        
  • Solid black shadows, or shadows so big they look like smudges.
    • 
        
  • text-shadow on body text.
    • 
        
  • Relying on a shadow alone to separate a card from its background, especially in dark mode.
    • 
        
  • Gradient text with no fallback colour, which can vanish entirely.
    • 
        
  • Blend modes that destroy text contrast.
