Grid

Grid controls rows and columns at the same time. Define the tracks on the container, and items fill the cells in order, or go exactly where you place them by line number or by name.

You'll be able to

  • Define columns and rows with fr, repeat(), gap and minmax().
  • Explain the difference between the explicit and the implicit grid.
  • Place items by line number, and by name with grid-template-areas.
  • Line up nested content with subgrid.

What is grid layout?

A grid is a set of horizontal and vertical lines that make columns and rows. Designers have used them on paper for centuries, because they make a page look consistent: things line up from section to section.

CSS Grid lets you build that structure in the browser. Flexbox lines items up in one direction; Grid handles two at once. The rows and columns are called tracks, and the spaces between them are gutters (in CSS, gap).

Creating your grid in CSS

Defining a grid

display: grid on the container makes its direct children grid items, but on its own it just stacks them in one column. Add columns with grid-template-columns:

.container {
  display: grid;
  grid-template-columns: 200px 200px 200px;
}

Flexible grids with the fr unit

Fixed pixel columns don't adapt to the screen. The fr unit means "a fraction of the available space", so 1fr 1fr 1fr makes three equal columns at any width, and 2fr 1fr 1fr makes the first twice as wide as the others. You can mix units: in 200px 1fr, the 200px column is sized first and the 1fr column takes what's left.

Gaps between tracks

column-gap and row-gap add space between tracks, and the gap shorthand sets both. Gaps can be lengths or percentages, but not fr.

Repeating track listings

repeat(3, 1fr) is a shortcut for 1fr 1fr 1fr. You can repeat a pattern too: repeat(2, 2fr 1fr) is 2fr 1fr 2fr 1fr.

Implicit and explicit grids

The tracks you define with grid-template-columns and grid-template-rows make the explicit grid. When there are more items than cells, the browser adds extra rows to hold them: that's the implicit grid. Implicit rows are sized auto (as tall as their content) unless you set grid-auto-rows:

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: 100px;   /* every implicit row is 100px */
}

The minmax() function

A fixed row height has the same problem as any fixed height: content that needs more room overflows. minmax(100px, auto) means "at least 100px, but taller if the content needs it".

As many columns as will fit

Put repeat() and minmax() together and you get the most useful line of Grid:

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
}

Read it as: "fit as many columns as you can, each at least 220px wide, and share any extra space equally." On a phone you get one column, on a laptop four, with no media queries. Pick the last option in the Build a grid playground above and resize your window to watch it.

Line-based placement

So far items have filled the cells in order. You can also place an item exactly, using the numbered lines between tracks. A grid with 4 columns has 5 column lines, numbered from 1 at the left (in English). Lines also count backwards from the end: -1 is always the last line.

header {
  grid-column: 1 / -1;   /* from the first line to the last: full width */
  grid-row: 1;
}
article {
  grid-column: 2 / 4;    /* from line 2 to line 4: two columns */
}

grid-column is shorthand for grid-column-start and grid-column-end; grid-row works the same way. Instead of an end line you can say how many tracks to cover: grid-column: 2 / span 2.

Positioning with grid-template-areas

Another way to place items is to draw the layout with names. grid-template-areas takes one quoted string per row, with one name per column. Then each item says which area it goes in with grid-area:

.page {
  display: grid;
  grid-template-columns: 1fr 3fr;
  grid-template-areas:
    "header  header"
    "sidebar content"
    "footer  footer";
}
header { grid-area: header; }
aside  { grid-area: sidebar; }
main   { grid-area: content; }
footer { grid-area: footer; }

The rules are strict:

  • Every row must have the same number of cells, and every cell must be filled.
  • Repeat a name to make an area span cells. Use . for an empty cell.
  • Each area must be a rectangle: no L-shapes, and no area in two separate places.

If a rule is broken, the whole declaration is ignored.

Nesting grids and subgrid

A grid item can be a grid container too, just like nested flex boxes. A card in a page grid might use its own grid to lay out its title, text and button.

The catch is that a nested grid's tracks know nothing about its neighbours. If three cards sit side by side and one has a two-line title, its text starts lower than the others. subgrid fixes this: the nested grid uses its parent's tracks instead of making its own.

.card {
  display: grid;
  grid-row: span 3;              /* take three rows of the parent grid */
  grid-template-rows: subgrid;   /* and use those rows for title, text, button */
}

Grid frameworks

Before CSS Grid, people used grid frameworks: libraries of classes that faked a grid, often with 12 or 16 columns. Grid makes most of them unnecessary. If you want a 12-column design grid, it's one line, and items are placed with line numbers:

.page { display: grid; grid-template-columns: repeat(12, 1fr); gap: 20px; }
header { grid-column: 1 / -1; }   /* all 12 */
aside  { grid-column: 1 / 4; }    /* 3 columns */
main   { grid-column: 4 / -1; }   /* the other 9 */

Key ideas

  • display: grid and the track lists go on the container. fr shares out the available space; repeat() saves typing.
  • Tracks you define are the explicit grid. Extra rows the browser adds are implicit, sized by grid-auto-rows.
  • minmax(100px, auto) sets a minimum but lets the track grow. repeat(auto-fit, minmax(220px, 1fr)) fits as many columns as there's room for.
  • Place items by line number (grid-column: 1 / -1) or by name (grid-template-areas + grid-area).
  • subgrid lets a nested grid share its parent's tracks, so content lines up across cards.

Common mistakes

  • Setting grid-template-columns on the items instead of the container.
  • A grid-template-areas layout with an uneven row or an L-shaped area, so the whole thing is ignored.
  • Mixing up lines and tracks: grid-column: 1 / 3 covers two columns, not three.
  • Fixed grid-auto-rows heights that make text overflow. Use minmax().
