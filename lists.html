Three kinds of list

Lists are everywhere on the web, often where you wouldn't expect them. A row of links in a site's menu is a list. So is a set of steps, a set of product features, or a glossary. HTML gives you three kinds:

  • <ul>, an unordered list, when the order doesn't matter, like gear to pack.
  • <ol>, an ordered list, when it does, like directions. The browser numbers the items for you.
  • <dl>, a description list, for pairs of terms and descriptions, with <dt> and <dd>.

In the first two, every item is an <li>, and <li>s are the only things allowed directly inside. To make a sub-list, put the inner list inside an item, after its text:

<ul>
  <li>Water
    <ul>
      <li>Two liters in summer</li>
    </ul>
  </li>
  <li>Map</li>
</ul>

Never type your own numbers or dashes into list items. Let the browser draw the markers, then change them with CSS: list-style-type picks the marker, and ::marker lets you color it.

Navigation menus are usually a <ul> inside a <nav>, with the bullets removed and the items laid out in a row. It's still a list of links, so screen readers announce "list, 4 items" and visitors know what to expect.

Watch out

list-style: none removes the bullets but not the indent. Lists also have a default padding-left, so set padding: 0 too.

Key ideas

  • <ul> when order doesn't matter, <ol> when it does, <dl> for terms and their descriptions.
  • A list's only direct children are <li>s (or <dt>/<dd> in a dl).
  • To nest a list, put the inner list inside an <li>, after its text.
  • Navigation menus are usually a <ul> inside a <nav>, with bullets removed.

Common mistakes

  • Putting a nested <ul> directly inside the outer <ul> instead of inside an <li>.
  • Typing your own numbers or dashes into list items.
  • Removing bullets but not the default padding-left, leaving a mysterious indent.
  • Using <br> between lines instead of real list items.
