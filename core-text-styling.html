Fundamental Text Styling

Most of what's on a web page is text, so how it reads matters more than almost any other design choice. CSS splits text styling in two: the font itself, and how the text is laid out.

You'll be able to

  • Write a font stack that always falls back to something sensible.
  • Set font size, style, weight, case, decoration and shadows.
  • Lay text out with alignment, line height, letter and word spacing, and a readable line length.
  • Read and write the font shorthand.
Read

What is involved in styling text in CSS?

Text sits inside its element's content box and flows from the start of the line to the end, wrapping onto new lines. You can't select a single word or line with CSS, only whole elements (with two exceptions, ::first-line and ::first-letter). The properties fall into two groups:

  • Font styles change the letters themselves: which font, how big, bold, italic, colour.
  • Text layout styles change the space around them: alignment, line spacing, letter and word spacing.

Fonts

Color

color sets the colour of the text (and of text decorations like underlines). It's named color, not font-color or text-color.

Font families

font-family names the font to use. It only works if the font is available: installed on the visitor's computer, or downloaded as a web font (next lesson). A few web safe fonts, like Arial, Verdana, Georgia and Times New Roman, are on nearly every computer.

Because you can't be sure, list several fonts in order of preference. That's a font stack: the browser uses the first one it has. Always end with a generic family name, which every browser maps to some font it does have:

p {
  font-family: "Trebuchet MS", Verdana, sans-serif;
}

Font size

font-size takes any length. Browsers default to 16px. Set sizes in rem so they follow the visitor's text-size setting (1rem is 16px by default, 1.5rem 24px). Watch out for em on font sizes: it's relative to the parent's font size, so it compounds through nested elements.

Heading sizes look best when they belong together. A type scale multiplies each level by the same ratio.

Font style, font weight, text transform, and text decoration

  • font-style: italic or normal. Use it to un-italicise, say, an <em>.
  • font-weight: normal, bold, or a number from 100 to 900 (400 is normal, 700 bold), if the font has those weights.
  • text-transform: uppercase, lowercase or capitalize. It changes how text looks, not the text itself, so a screen reader still reads the original.
  • text-decoration: underline, overline, line-through, or none (often used on links). It's a shorthand, so underline wavy red works too.

Text drop shadows

text-shadow: 4px 4px 5px red sets the shadow's horizontal offset, vertical offset, blur and colour. Separate several shadows with commas.

Text layout

  


Text alignment

    
text-align: left, right, center or justify. Left-align long paragraphs (in English); centred text is fine for a short heading but hard to read for more than a line or two, and justify can leave rivers of gaps.

    
Line height

    
line-height sets the height of each line. Write it without a unit, like 1.6, so it's a multiple of the font size and scales with it. Around 1.4 to 1.8 is comfortable for body text.

    
Letter and word spacing

    
letter-spacing and word-spacing add (or remove, with negative values) space between letters and words. A little extra letter spacing helps small uppercase text.

    
Line length

    
Not a property of its own, but it matters most: lines of about 45 to 75 characters read best. Limit paragraphs with max-width: 65ch, where ch is roughly one character wide.

    Other properties worth looking at
    
    
    There are many more: font-variant (small caps), text-indent, text-overflow (an ellipsis for cut-off text), white-space (whether text wraps), word-break, text-wrap: balance (evens out the lines of a heading) and writing-mode (vertical text). Look them up on MDN when you need them.

    Font shorthand
    
  
    

    The font shorthand sets most font properties in one line. The order is strict: optional style, variant and weight first, then the required size (with an optional /line-height), then the required family last:
    
    
    font: italic bold 1.25rem/1.5 Georgia, serif;
    
    
    Leave out the size or the family and the whole declaration is ignored. And anything you leave out is reset to its default, so put font before any longhands you want to keep.

      Key ideas
      
      
        
        
      • End every font stack with a generic family: serif, sans-serif or monospace.
        • 
        
      • Use rem for font sizes; at least 1rem (16px) for body text.
        • 
        
      • Unitless line-height around 1.4 to 1.8; lines of 45 to 75 characters.
        • 
        
      • text-transform changes how text looks, not what it says.
        • 
        
      • The font shorthand needs a size and a family, in that order, and resets what you leave out.
        • 
      
      
    
      
    
      
      
      Common mistakes
      
      
        
        
      • A font name with spaces and no quotes, or a stack with no generic fallback.
        • 
        
      • font-color or text-color: the property is color.
        • 
        
      • Centring or justifying long paragraphs.
        • 
        
      • Typing headings in capitals in the HTML instead of using text-transform.
        • 
        
      • A font shorthand without a size, which throws the whole declaration away.
