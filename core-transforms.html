Transforms

Transforms move, turn, resize and slant an element after the page is laid out, without nudging anything around it. That makes them ideal for hover effects, icons and small bits of motion.

You'll be able to

  • Use translate, rotate, scale and skew, as functions and as individual properties.
  • Explain why transforms don't affect layout, and why the order of functions matters.
  • Move the pivot point with transform-origin.
  • Add depth to a 3D transform with perspective.

CSS transforms properties

The transform property takes one or more functions, separated by spaces:

.badge {
  transform: translateY(-4px) rotate(-3deg) scale(1.1);
}
  • translate() moves it (translateX(), translateY()).
  • rotate() turns it, in deg or turn. A number with no unit does nothing.
  • scale() resizes it: 1 is normal size, 2 double, 0.5 half.
  • skew() slants it (skewX(), skewY()).

Transforms are drawn after layout, so the browser keeps the element's original space and nothing around it moves. A card can grow on hover without shoving its neighbours.

transform-origin sets the point the element turns and scales around. The default is the centre; transform-origin: top left makes it pivot from the corner, like a door on a hinge.

Individual transform properties

    
There are also separate translate, rotate and scale properties. They're easier to read, and they don't replace each other. With the transform property, a hover rule that sets transform: scale(1.1) wipes out an earlier rotate(-3deg). With separate properties, scale: 1.1 just adds to rotate: -3deg.

    
.stamp { rotate: -3deg; }
.stamp:hover { scale: 1.1; }   /* still rotated */

Examples

  


Rotating

    
rotate: 90deg; transform-origin: bottom left; swings an element a quarter-turn around its bottom-left corner instead of its centre.

    
Skewing and translating

    
When you combine functions, order matters. Each function works in the space left by the ones before it: rotate first, and "right" now points diagonally, so a following translateX() moves the element diagonally too.

Same functions, different order
Transform functions apply from right to left, and each one changes the direction the next one uses.

A

transform: rotate(45deg) translateX(140px);
B
Turn first, so "right" is now tilted 45° downward, and it slides along that tilted line.

Four everyday uses

  

    
Center anything
centered
.badge {
  position: absolute;
  top: 50%; left: 50%;
  transform: translate(-50%, -50%);
}
top/left: 50% puts the corner in the middle. The translate pulls it back by half its own size.

    
Lift on hover
Hover or Tab to me
.card { transition: transform 0.2s; }
.card:hover {
  transform: translateY(-6px);
}

3D specific CSS properties

  


Transforms also work in three dimensions: rotateX() and rotateY() tip an element towards or away from you, and translateZ() moves it nearer. Without perspective, though, 3D looks flat.

    
Perspective

    
Set perspective on the parent: the distance between the viewer and the page. A small value (250px) is like holding your face close, with dramatic distortion; a large one (1000px) is subtle. perspective-origin moves the viewer's eye: left, top right and so on.

    
.scene { perspective: 600px; }
.card  { transform: rotateY(40deg); }

Key ideas

      
    
        
  • Transforms change how an element is drawn, not the space it takes.
    • 
        
  • Functions in one transform apply right to left, and order changes the result.
    • 
        
  • A second transform replaces the first; the individual rotate, scale and translate properties combine.
    • 
        
  • transform-origin moves the pivot point.
    • 
        
  • 3D needs perspective on the parent.
    • 
      

    

    

      
Common mistakes

      
    
        
  • rotate(45) with no unit.
    • 
        
  • Overriding a rotation by setting transform: scale() on hover.
    • 
        
  • Using transforms to build layout: the space doesn't move with the element.
    • 
        
  • Putting perspective on the element being rotated instead of its parent.
