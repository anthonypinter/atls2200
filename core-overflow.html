Overflow

Overflow happens when content is bigger than its box. CSS doesn't hide it by default: it lets it spill out so you notice. Here's how to control it on each axis, and how to track down the element that makes a whole page scroll sideways.

You'll be able to

  • Explain why CSS shows overflowing content by default.
  • Choose between visible, clip, hidden, scroll and auto, and set each axis separately.
  • Shorten one-line text with an ellipsis, and let long words and links wrap.
  • Track down the element that makes a whole page scroll sideways.

What is overflow?

Overflow is what happens when there's too much content to fit in a box: a long paragraph in a card with a fixed height, a giant image in a narrow column, or a long URL with no spaces to break at.

It only happens when a box's size is constrained. A box with no set height just grows to fit its content, as you saw in Sizing. Set height: 100px, though, and anything beyond 100px has to go somewhere.

Read

CSS tries to avoid "data loss"

By default, CSS lets overflowing content spill out of its box, visibly, even when it overlaps whatever comes next. That looks messy, but it's deliberate: if CSS silently hid the extra content, you might never notice that part of your page was missing. A mess is a problem you'll see and fix.

The lesson for your own CSS: be careful about fixing the height of anything that holds text. Text gets longer when it's translated, when someone sets a bigger default font, or when the screen gets narrower. Let the content decide the height wherever you can.

The overflow property

When you do need to control overflow, the overflow property decides what happens:

  • visible, the default, lets it spill out.
  • clip cuts off anything outside the box.
  • hidden also cuts it off, but the box can still be scrolled by code.
  • scroll always shows scrollbars.
  • auto shows scrollbars only when they're needed. It's usually the right choice.

Hiding overflowing content

overflow: clip cuts content off at the edge of the box (its padding edge, just inside the border). The cut-off part can't be reached at all, so only use it for things nobody needs to read, like a decorative shape that pokes out of a banner.

If clipping right at the edge looks too tight, overflow-clip-margin lets the content spill a little way past the edge before it's cut:

.banner {
  overflow: clip;
  overflow-clip-margin: 10px;
}

Scrolling overflowing content

overflow: auto keeps everything reachable: if the content doesn't fit, the box gets a scrollbar; if it does, there's no scrollbar at all. It's the safe choice for a box that has to stay a fixed size, like a chat window or a long list in a sidebar.

.trail-log {
  height: 200px;
  overflow: auto;
}

Controlling overflow on each axis

overflow is a shorthand for two properties: overflow-x (side to side) and overflow-y (up and down). You can set them separately, or give overflow two values, x first:

.code-sample { overflow-x: auto; }   /* scroll sideways only */
.strip { overflow: clip auto; }      /* clip x, scroll y */

One combination isn't allowed: a box can't scroll in one direction and spill visibly in the other. If one axis is scroll, auto or hidden, a visible on the other axis is quietly turned into auto.

Long words and one-line titles

    
Two text problems come up constantly. A long URL or word has no spaces to break at, so it pushes past its box. overflow-wrap: anywhere lets it break where it needs to. And a title that must stay on one line can end in an ellipsis (…) instead of spilling:

    
.title {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

Always displaying scrollbars

  


overflow: scroll shows scrollbars even when there's nothing to scroll, on systems that show scrollbars all the time. That's rarely what you want, but it does stop the layout jumping sideways when content grows and a scrollbar suddenly appears.

    
A better way to get that stability is overflow: auto plus scrollbar-gutter: stable, which reserves room for the scrollbar without drawing an empty one.

    
.panel {
  overflow: auto;
  scrollbar-gutter: stable;
}

The hidden value

  


overflow: hidden looks just like clip: extra content is cut off and there are no scrollbars. The difference is that a hidden box is still a scroll container. JavaScript can scroll it, and so can keyboard focus moving to a link inside the hidden part. That can leave the box scrolled to an odd position with no way for the user to scroll it back.

    
Use clip when you just want to cut content off, and hidden only when you're going to scroll the box with code (a carousel, for example).

Unwanted overflow in web design

  


Most overflow you meet won't be a box you chose to constrain. It'll be a bug: text spilling out of a card that looked fine with the sample text, or a whole page that scrolls sideways on a phone because one element is wider than the screen (a fixed width: 400px, a big image, a long link).

    
To catch these early, test your layouts with much more and much less content than you expect, and with a larger browser font size. When you find overflow, fix the cause instead of hiding it.

    
Watch out
overflow: hidden on the body hides the sideways scroll, but the content is still too wide and now some of it is unreachable. Find the element that's too wide and make it flexible.

Key ideas

      
    
        
  • Overflow only happens when a box's size is constrained. Let content decide the height where you can.
    • 
        
  • By default overflow is visible, so you notice the problem instead of losing content.
    • 
        
  • auto adds scrollbars only when needed; clip cuts content off; hidden cuts it off but can still be scrolled by code.
    • 
        
  • overflow-x and overflow-y control each axis. A scrolling axis turns visible on the other into auto.
    • 
        
  • overflow-wrap: anywhere breaks long words; text-overflow: ellipsis shortens one-line text.
    • 
      

    

    

      
Common mistakes

      
    
        
  • Fixed pixel widths, like width: 380px, wider than a phone screen.
    • 
        
  • Putting overflow: hidden on body to hide the sideways scroll instead of fixing the cause.
    • 
        
  • Fixed height on a text box that later gets more text, translated text, or larger font settings.
    • 
        
  • Using overflow: scroll, which shows scrollbars even when nothing overflows.
