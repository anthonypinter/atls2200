What you've covered

This part was about structure and meaning. Before any styling, HTML says what each piece of a page is, and browsers, search engines and screen readers all rely on that.

  • How the Web Works: The browser requests files from a server by URL, and the server answers with a status code.
  • HTML Syntax: Elements nest like boxes, and attribute values always go in quotes.
  • Document Structure: Every page has a doctype, then a head for information and a body for content.
  • The Head & Metadata: The title, description and Open Graph tags decide how a page appears in tabs, searches and shared links.
  • Text Semantics: One h1, headings in order, and strong or em for meaning rather than looks.
  • Lists: ul when order doesn't matter, ol when it does, dl for terms and descriptions.
  • Semantic Elements: header, nav, main, article and footer name the parts of a page.
  • Links & Paths: Relative paths start from the current file, and ../ climbs one folder.
  • Tables: Tables are for data, with th and scope to label rows and columns.
  • Forms & Inputs: Every input needs a label, a name and the right type.
  • Images & Alt Text: Alt text describes what an image means in context, and decoration gets alt="".
  • Image Formats: JPEG or WebP for photos, SVG for logos, PNG for screenshots, and resize before you upload.
  • Video & Audio: Players need controls, several sources, and captions.
  • Embeds & iframes: An iframe needs a title, lazy loading, and an aspect-ratio to fit phones.
