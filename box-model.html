Every element is a box

Open DevTools on any page and hover over an element. The browser highlights a rectangle. Every element is a box, even a heading or a link that looks like it's just text. The rules for how that box is built are called the box model, and knowing them is how you predict how big things will be.

Each box has four layers, from the inside out:

  • Content is the text or image itself. By default, width and height size only this part.
  • Padding is space between the content and the border. It's inside the box, so it shows the background color.
  • Border is the line around the padding. It can be any width, or none at all.
  • Margin is space outside the border that pushes other boxes away. It's always transparent.

Here's the part that surprises people. By default, width sets only the content, and padding and border are added on top. This card is 352px wide on the page, not 300px:

.card {
  width: 300px;
  padding: 20px;          /* + 20 on each side = 340px */
  border: 6px solid;      /* + 6 on each side  = 352px */
}

Add box-sizing: border-box and the browser does the math the other way: the whole box, padding and border included, is 300px, and the content shrinks to fit. That's much easier to plan with, which is why most stylesheets start with * { box-sizing: border-box; }.

Tip

In DevTools, the Computed tab draws the box model for whatever element you select, with the size of every layer. When a box is bigger than you expected, look there first.

One more rule: when two vertical margins touch, they don't add up. They collapse into the larger one. A heading with margin-bottom: 30px above a paragraph with margin-top: 20px leaves 30px between them, not 50px.

Key ideas

  • By default (content-box), width sets only the content. Padding and border are added on top.
  • With border-box, width includes padding and border, so the box stays the size you asked for.
  • Margin is space outside the border. It's transparent and never part of the width.
  • Most developers start every stylesheet with * { box-sizing: border-box; }.

Common mistakes

  • Setting width: 100% plus padding and getting a horizontal scrollbar.
  • Using padding when you wanted space between boxes (that's margin or gap).
  • Being surprised when two vertical margins collapse into one instead of adding together.
  • Forgetting the browser's default margin on body, h1, and p.
