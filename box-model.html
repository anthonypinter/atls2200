CSS Basics · The Box Model

Box Model Explorer

Every element is a box made of four layers: content, padding, border, and margin. Adjust each layer and see how much space the box really takes up.

Key ideas

  • By default (content-box), width sets only the content. Padding and border are added on top.
  • With border-box, width includes padding and border, so the box stays the size you asked for.
  • Margin is space outside the border. It's transparent and never part of the width.
  • Most developers start every stylesheet with * { box-sizing: border-box; }.

Common mistakes

  • Setting width: 100% plus padding and getting a horizontal scrollbar.
  • Using padding when you wanted space between boxes (that's margin or gap).
  • Being surprised when two vertical margins collapse into one instead of adding together.
  • Forgetting the browser's default margin on body, h1, and p.
