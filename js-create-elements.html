Creating & Removing Elements

JavaScript can build new elements and add them to the page, then take them away again. This shopping list is MDN's DOM scripting exercise. Add and delete items and watch which lines of code run.

You'll be able to

  • Build a new element with createElement and fill it with text and classes.
  • Add elements to the page with append and remove them with remove.
  • Explain why typed text should go in textContent, not innerHTML.
Read

Building the page from code

So far you've changed elements that were already in the HTML. JavaScript can also build new ones, which is how a to-do list grows when you add an item, or how search results appear. It takes three steps:

const li = document.createElement("li");   // 1. make it
li.textContent = "Trail mix";               // 2. fill it
li.classList.add("item");
list.append(li);                            // 3. attach it

createElement() makes an element in memory. It isn't on the page yet, and it won't show up anywhere until you attach it to something that is. Forgetting that last step is the most common reason a new element never appears. append() adds it as the last child; prepend() adds it as the first. You'll also see the older appendChild(), which works the same way.

To take an element away, call remove() on it: li.remove().

An element can only be in one place at a time. Appending an element that's already on the page moves it rather than copying it. To make a copy, use cloneNode(true).

There's a shortcut you'll see a lot: setting innerHTML to a string of HTML. It's handy for building markup you wrote yourself. But never use it for text a visitor typed. If someone types <img src=x onerror=…>, innerHTML turns it into a real element, and the code inside runs. textContent shows exactly what was typed and never runs it.

Tip

After adding an item to a list, clear the input and put focus back in it with input.focus(), so people can type the next one straight away.

    Key ideas
    
      
      
        
    • Make an element: const li = document.createElement("li");
      • 
        
    • Fill it: li.textContent = "Milk";, li.classList.add("item");
      • 
        
    • Put it on the page: list.appendChild(li), or list.append(li) (which can also take text). prepend() adds at the start.
      • 
        
    • Take it off: li.remove(). (MDN's exercise uses the older list.removeChild(li), which works the same.)
      • 
        
    • Appending an element that is already on the page moves it. Use cloneNode(true) to make a copy.
      • 
        
    • Use textContent for anything a person typed. It shows the text exactly as typed and never runs it as HTML.
      • 
      
    
    
    
    
    
      
    Common mistakes
    
      
      
        
    • Creating an element but never appending it, so nothing appears and there's no error.
      • 
        
    • Using innerHTML with user input. Someone can type HTML that runs code on your page (cross-site scripting).
      • 
        
    • Forgetting preventDefault() on the form, so the page reloads and the list is wiped.
      • 
        
    • Adding the delete listener to the wrong thing, such as the whole list instead of each item's button.
