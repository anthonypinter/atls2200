Variables

A program needs to remember things: a score, a name, whether a menu is open. Variables give values a name so you can use and change them later.

You'll be able to

  • Declare and initialize variables with let and const, and know why to avoid var.
  • Name variables so they work and read well.
  • Recognise the main types of value, and check them with typeof.
  • Choose between const and let.

What is a variable?

A variable is a container for a value: a name that holds something so you can use it later. Think of a labelled box.

Variable example

MDN's example counts button presses. The count lives in a variable, and each press adds one to it:

const buttonA = document.querySelector("#button_A");
let count = 0;

buttonA.addEventListener("click", () => {
  count += 1;
  headingA.textContent = `${count} clicks so far`;
});

Initializing a variable

Initializing means giving a variable its first value, with =. You can do it on its own line or, usually, at the same time as declaring:

let myName;
myName = "Chris";          // initialize later

let myDog = "Rover";       // declare and initialize at once

A note about var

Older code uses var. It works, but it has quirks that cause bugs: you can use a var before the line that declares it (it's "hoisted" and quietly holds undefined), and you can declare the same name twice without any error. let and const, added in 2015, catch both mistakes. Use them, and read var as "old code".

Read

Updating a variable

Once a let variable exists, give it a new value with =, without let. Writing let again is an error: you only declare once.

let miles = 6.7;
miles = miles + 1;   // now 7.7

An aside on variable naming rules

Names can contain letters, numbers, _ and $, but can't start with a number, contain spaces, or be one of JavaScript's reserved words like let or function. Use "lower camel case" for multi-word names: trailName, isOpen. Names are case-sensitive, so score and Score are two different variables. Choose names that say what the value is.

    Variable types
    
  
    

    Every value has a type. The main ones:
    
    
    Numbers
    
    
    Whole numbers or decimals, with no quotes: let miles = 6.7;
    
    
    Strings
    
    
    Text, in quotes: let trail = "Mesa"; Quotes always make a string, even "42".
    
    
    Booleans
    
    
    Just true or false, often the result of a comparison: let isLong = miles > 5;
    
    
    Arrays
    
    
    A list of values in square brackets, counted from 0: let trails = ["Mesa", "Royal Arch"]; then trails[0] is "Mesa".
    
    
    Objects
    
    
    A group of named values in curly braces: let hike = { name: "Mesa", miles: 6.7 }; then hike.name is "Mesa".

    Dynamic typing
    
  
    

    JavaScript is dynamically typed: you don't say what type a variable holds, and the same let variable can hold a string now and a number later. typeof tells you what type a value is right now.

    Constants in JavaScript
    
  
    

    const creates a variable that can't be given a new value. It must be initialized when it's declared, and = on it later is an error. But a const holding an object or array can still have its contents changed: the box can't be swapped, but what's inside it can.
    
  
    

  
    

  
    Read
    When to use const and when to use let
    
  
    

    Use const by default, and let only when you know the value will be reassigned, like a counter or a score. That way, anyone reading your code knows which values move, and JavaScript stops you if you change one by accident.

    Key ideas
    
      
      
        
    • A variable is a named container for a value. Declare it once, with let or const.
      • 
        
    • A declared but empty variable is undefined; an undeclared name is a ReferenceError.
      • 
        
    • Avoid var: it's hoisted and can be redeclared without warning.
      • 
        
    • Main types: numbers, strings, booleans, arrays and objects. typeof tells you which.
      • 
        
    • const by default; let when the value will be reassigned. A const object's contents can still change.
      • 
      
    
    
    
    
    
      
    Common mistakes
    
      
      
        
    • Writing let again when updating a variable.
      • 
        
    • Putting quotes around a number: "42" is a string.
      • 
        
    • Names with spaces or starting with a number, like 2ndTrail.
      • 
        
    • Using const for a counter, then trying to add to it.
