Lists

Packing lists, directions, glossaries, navigation menus: lists are everywhere. HTML has three kinds. Learn which to use, how to nest them, and the attributes that change how they count.

You'll be able to

  • Choose between an unordered, an ordered and a description list.
  • Write each one with the right child elements.
  • Nest a list inside a list item, correctly.
  • Change how an ordered list counts with start, reversed and type.
Read

Unordered lists

When the order doesn't matter, like a packing list, use an unordered list. The list is a <ul>, and each item is an <li> (list item) inside it. Browsers show a bullet before each item:

<ul>
  <li>Water</li>
  <li>Snacks</li>
  <li>Rain jacket</li>
</ul>

A <ul> may only contain <li>s. Text, headings and paragraphs go inside the list items.

Read

Ordered lists

When order matters, like directions or a ranking, use an ordered list, <ol>. The items are still <li>s, and the browser numbers them for you:

<ol>
  <li>Park at Chautauqua.</li>
  <li>Take the Bluebell Road uphill.</li>
  <li>Turn left at the Royal Arch sign.</li>
</ol>

Never type the numbers yourself. Add a step later and the browser renumbers everything. Three attributes change the counting: start="5" begins at 5, reversed counts down, and type="a", "A", "i" or "I" uses letters or Roman numerals.

Nesting lists

  

    
A step can have sub-steps, and a category can have items. To nest a list, put the inner list inside an <li> of the outer one, after that item's text:

    
<ol>
  <li>Pack your bag:
    <ul>
      <li>Water</li>
      <li>Snacks</li>
    </ul>
  </li>
  <li>Drive to the trailhead.</li>
</ol>

    
Watch out
Putting the inner <ul> directly inside the outer list, between two <li>s, looks almost right but is invalid. Screen readers lose track of which item the sub-list belongs to.

    Description lists
    
  
    
    
    A description list pairs terms with descriptions, like a glossary. The list is a <dl>; each term is a <dt> (description term) and each description a <dd> (description details):
    
    
    <dl>
  <dt>Switchback</dt>
  <dd>A zigzag in a trail that makes a steep slope easier to climb.</dd>
  <dt>Cairn</dt>
  <dd>A pile of stones that marks the route.</dd>
  <dd>Don't build your own: they can mislead other hikers.</dd>
</dl>
    
    
    A term can have several descriptions, as Cairn does above, and several terms can share one description. Browsers indent the descriptions.

    Key ideas
    
      
      
        
    • <ul> when order doesn't matter, <ol> when it does. Items are <li>s.
      • 
        
    • <dl> pairs <dt> terms with <dd> descriptions.
      • 
        
    • A nested list goes inside an <li>, after its text.
      • 
        
    • start, reversed and type change an ordered list's counting.
      • 
        
    • Navigation menus are usually lists of links.
      • 
      
    
    
    
    
    
      
    Common mistakes
    
      
      
        
    • Typing numbers or dashes into the items instead of using <ol> or <ul>.
      • 
        
    • Text or a <p> directly inside <ul>, outside any <li>.
      • 
        
    • Nesting a list between two <li>s instead of inside one.
      • 
        
    • Choosing <ul> or <ol> for the bullet style. That's CSS's job.
