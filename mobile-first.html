Responsive checklist

Tick these off for your own project. Your checks are saved in this browser only.

    Key ideas

    • The phone layout is usually the simplest: one column. Starting there means less CSS to undo later.
    • Styles outside any media query apply everywhere. Media queries only add changes for wider screens.
    • Use min-width queries, listed from smallest to largest.
    • Add a breakpoint when the layout starts to look wrong as you widen the window, not at a specific device's width.

    Common mistakes

    • Designing for a laptop, then cramming it onto a phone with lots of max-width overrides.
    • Only testing by shrinking the browser window. Check on a real phone too.
    • Fixed widths like width: 960px on a wrapper, which cause sideways scrolling on phones.
    • Hiding important content on mobile instead of rearranging it.
