HTML Syntax

HTML is made of elements, and elements are made of tags, attributes and content. Learn the names for each part, then see how the browser treats spaces and special characters.

Part 1

Anatomy of an element

Click any part, or pick a name below.

Empty (void) elements have no closing tag
<img><br><hr><input><meta><link>

They can't hold content, so there's nothing to close. Writing <img /> with a slash is allowed but not needed.

Part 2

Whitespace collapses

Type extra spaces, tabs and blank lines. The browser squashes every run of whitespace into a single space.

What the browser shows

To start a new paragraph, use a new <p>. Use CSS for spacing, not lots of spaces or <br>s.

Key ideas

      
    
        
  • Elements nest like boxes inside boxes. Close the inner one before the outer one.
    • 
        
  • Attributes go in the opening tag, as name="value". Always quote the value.
    • 
        
  • Tag and attribute names aren't case-sensitive, but write them in lowercase.
    • 
        
  • Comments look like <!-- like this --> and don't appear on the page.
    • 
      

    

    

      
Common mistakes

      
    
        
  • Forgetting a closing tag, so everything after it gets the same formatting.
    • 
        
  • Curly "smart quotes" pasted from a word processor around attribute values.
    • 
        
  • Spaces around the equals sign in odd places, or missing quotes around values with spaces.
    • 
        
  • Using lots of &nbsp; or <br> to push things around. That's CSS's job.
