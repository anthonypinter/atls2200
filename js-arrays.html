Arrays

An array stores a list of values under one name, in order, with a numbered index starting at 0. Some methods change the array, and others just hand you back an answer. Try them below.

You'll be able to

  • Create an array and read items by their index.
  • Add and remove items with push, pop, shift, unshift and splice.
  • Tell which methods change the array and which return a new value.
Read

A list under one name

When you have several related values, like the trails in a guide, you don't want trail1, trail2, trail3. An array stores a whole list under one name, in order:

const trails = ["Mesa", "Royal Arch", "Chautauqua"];
trails[0]                  // "Mesa"
trails.length              // 3
trails[trails.length - 1]  // "Chautauqua"

Each item has an index, its position, and counting starts at 0. So the first item is [0], and the last is at length - 1. Asking for an index that doesn't exist gives undefined, not an error. To change an item, assign to its index: trails[1] = "Flagstaff".

Arrays come with methods for adding and removing items. push() and pop() add and remove at the end. unshift() and shift() work at the start. splice() removes items from the middle.

Some methods change the array itself; others leave it alone and hand you an answer. push() changes it. includes("Mesa") just answers true or false, and slice() and join() return something new. Knowing which kind you're using saves a lot of confusion.

Arrays can hold any type of value: numbers, strings, even objects or other arrays. And split() and join() convert between strings and arrays.

Tip

A const array can still change. const only means the name always points to the same array; you can still push and pop its contents.

Key ideas

      
    
        
  • Create an array with square brackets: const trails = ["Mesa", "Royal Arch"];
    • 
        
  • Read an item by its index: trails[0] is the first item. The last one is trails[trails.length - 1].
    • 
        
  • Change an item: trails[1] = "Flagstaff";
    • 
        
  • push() and pop() work at the end; unshift() and shift() work at the start. splice() removes from the middle.
    • 
        
  • Arrays can hold any type, including other arrays and objects.
    • 
        
  • Convert between strings and arrays with split() and join().

Common mistakes

      
    
        
  • Starting to count at 1. trails[1] is the second item.
    • 
        
  • Reading trails[trails.length]. It's one past the end, so you get undefined.
    • 
        
  • Saving what push() returns and expecting the array: const list = trails.push("x"); gives the new length.
    • 
        
  • Thinking indexOf() returns false when nothing is found. It returns -1. Use includes() for a true/false answer.
