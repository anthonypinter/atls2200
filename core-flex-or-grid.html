Flexbox or Grid?

Both can build most layouts, but each has a sweet spot. Flexbox arranges items along one line and lets their content decide their size. Grid lays out rows and columns together. Real pages use both, often one inside the other.

One dimension or two?

You can build most layouts with either Flexbox or Grid, which is why people argue about which is better. They're not competitors. Each has a sweet spot.

The key difference is dimensions. Flexbox is one-dimensional: it arranges items along a single row or column. When flex items wrap onto a second line, that line is laid out on its own, so items in different lines don't line up with each other. Grid is two-dimensional: you define columns and rows, and items line up in both directions at once.

The classic sign you picked wrong is a card gallery built with Flexbox: the last row has two cards, and they stretch to fill the whole width. With Grid, they keep the same width as the cards above.

Content out, or layout in?

A second way to decide is to ask where the sizes come from.

  • Content out: the items' own sizes should decide the layout. A row of buttons, a logo next to a nav, tags that wrap like words. That's Flexbox.
  • Layout in: you draw the rows and columns first and place content into them. A card gallery, a page with a sidebar, a photo layout where one item spans several cells. That's Grid.

A few things only one of them can do. Only Grid can make an item span several rows, and only Grid keeps columns lined up across wrapped rows. Flexbox is simpler for a single row whose items are different sizes, and for pushing one item to the end with margin-left: auto.

Tip

Ask yourself: "Do I care about columns lining up?" If yes, use Grid. If you just need things in a row, spaced nicely, use Flexbox.

Rule of thumb

Content out: if the items' sizes should decide the layout (a row of buttons, tags, a navbar), use Flexbox. Layout in: if you want to draw the rows and columns first and drop items into them (a gallery, a page, a dashboard), use Grid. Real sites use both, often nested.

Using them together

Most real pages use both. A common pattern: Grid for the overall structure (the page, a gallery of cards), and Flexbox inside each piece (the card's header, its row of buttons).

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 16px;
}
.card {
  display: flex;
  flex-direction: column;
}
.card .btn {
  margin-top: auto;   /* push the button to the bottom of the card */
}

Grid makes every card in a row the same height. Inside each card, a flex column with margin-top: auto on the button pushes the button to the bottom, so the buttons line up even when the text above them is different lengths.

Pick the right tool

Key ideas

  • Flexbox is one-dimensional: a row or a column. Wrapped lines don't line up with each other.
  • Grid is two-dimensional: columns line up from row to row.
  • Content out (sizes from the items) → Flexbox. Layout in (tracks first, then content) → Grid.
  • Only Grid can make one item span several rows and columns.
  • It's normal to put a flex container inside a grid item, or a grid inside a flex item.

Common mistakes

  • Building a card gallery with Flexbox and getting a stretched last row.
  • Adding lots of wrapper divs to fake a two-dimensional layout with Flexbox.
  • Using Grid for a simple row of buttons and fighting fixed column widths.
  • Thinking one is "better." They solve different problems.
