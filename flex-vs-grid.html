Flexbox vs Grid

Both can build most layouts, but each has a sweet spot. Flexbox arranges items along one line and lets their content decide their size. Grid lays out rows and columns together. Pick a layout and compare.

Two tools, different jobs

You can build most layouts with either Flexbox or Grid, which is why people argue about which is better. They're not competitors. Each has a sweet spot, and real sites use both, often on the same page.

The key difference is dimensions. Flexbox is one-dimensional: it arranges items along a single row or column, and lets each item's content help decide its size. When flex items wrap onto a second line, that line is laid out on its own, so items in different lines don't line up with each other. Grid is two-dimensional: you define columns and rows, and items line up in both directions.

A useful rule of thumb:

  • Reach for Flexbox for a row of things whose sizes come from their content: a nav bar, a set of buttons, a logo next to a title, tags that wrap.
  • Reach for Grid when columns must line up, or when you're defining the layout first and placing content into it: a card gallery, a page with a sidebar, a photo layout where one item spans several cells.

The classic sign you picked wrong is a card gallery built with Flexbox: the last row has two cards, and they stretch to fill the whole width. With Grid, they keep the same width as the cards above.

The two also nest freely. A page might use Grid for its overall layout, and each card inside might use Flexbox to line up its icon, title and button.

Tip

Ask yourself: "Do I care about columns lining up?" If yes, use Grid. If you just need things in a row, spaced nicely, use Flexbox.

Rule of thumb

Content out: if the items' sizes should decide the layout (a row of buttons, tags, a navbar), use Flexbox. Layout in: if you want to draw the rows and columns first and drop items into them (a gallery, a page, a dashboard), use Grid. Real sites use both, often nested.

Pick the right tool

This page uses Flexbox for everything. One part should be Grid.

Key ideas

  • Flexbox is one-dimensional: a row or a column. Wrapped lines don't line up with each other.
  • Grid is two-dimensional: columns line up from row to row.
  • Only Grid can make one item span several rows and columns.
  • It's normal to put a flex container inside a grid cell, or a grid inside a flex item.

Common mistakes

  • Building a card gallery with Flexbox and getting a stretched last row.
  • Adding lots of wrapper divs to fake a two-dimensional layout with Flexbox.
  • Using Grid for a simple row of buttons and fighting fixed column widths.
  • Thinking one is "better." They solve different problems.
