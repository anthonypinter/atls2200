Loops

Computers are good at doing the same thing over and over. A loop runs a block of code again and again: once for every item in a list, a set number of times, or until something changes.

You'll be able to

  • Loop through an array with for...of, and transform or filter it with map() and filter().
  • Count with a standard for loop, and use the index.
  • Leave a loop early with break, and skip an item with continue.
  • Use while and do...while, and pick the right loop for the job.
Read

Why are loops useful?

Say you have a list of 50 trails and want to show each name. You could write console.log() 50 times, or write it once and let a loop repeat it. Loops are how programs work through lists: every product in a shop, every photo in a gallery, every guess in a game.

Looping code example

MDN's example draws 100 random circles on a canvas. The drawing code is written once, inside a loop that runs it 100 times:

for (let i = 0; i < 100; i++) {
  ctx.beginPath();
  ctx.fillStyle = "rgb(255 0 0 / 50%)";
  ctx.arc(random(WIDTH), random(HEIGHT), random(50), 0, 2 * Math.PI);
  ctx.fill();
}

With and without a loop

Without the loop you'd need the four drawing lines 100 times over: 400 lines instead of 6. And changing "100" to "1000" would mean 3,600 more lines instead of editing one number.

Looping through a collection

Most of the time you'll loop over a collection, usually an array.

The for...of loop

for...of runs its block once per item. Each time round, the variable (here trail) holds the current item. Each pass is one iteration.

const trails = ["Mesa", "Royal Arch", "Flagstaff"];
for (const trail of trails) {
  console.log(trail);
}

map() and filter()

Arrays also have methods that do the looping for you. map() calls a function on every item and collects the results in a new array. filter() calls a function on every item and keeps only the items where it returns true.

The standard for loop

  


A standard for loop counts. It has three parts, separated by semicolons:

    
for (let i = 0; i < 10; i++) {
  // runs with i = 0, 1, 2 … 9
}

    
    
      
  1. An initializer, let i = 0: a counter, run once at the start.
    2. 
      
  2. A condition, i < 10: checked before each pass; the loop stops when it's false.
    3. 
      
  3. A final expression, i++: run after each pass.

    while and do...while
    
  
    

    A while loop repeats as long as its condition is true. It's like a for loop with the initializer before it and the final expression inside it, and it's handy when you don't know in advance how many times to go round.
    
    
    do...while checks the condition at the end, so its block always runs at least once.
    
  
    

  
    

  
    

    Watch out
    Every loop needs a way to stop. Forget the i++ in a while loop and its condition never becomes false: it runs forever and freezes the page. If that happens, close the tab, then check what changes the condition.

    Which loop type should you use?
    
  
    

    For going through every item in an array, use for...of: it's the simplest and hardest to get wrong. If you need the index, or to count a set number of times, use a standard for loop. To build a new array from an old one, reach for map() or filter(). Use while when you don't know how many passes you'll need, and keep do...while for the rare "at least once" case.
    
  
    

  
    
    
    
      
    Key ideas
    
      
      
        
    • A loop runs a block repeatedly; each pass is an iteration.
      • 
        
    • for...of visits every item; map() transforms them; filter() keeps some.
      • 
        
    • for (let i = 0; i < n; i++): initializer, condition, final expression.
      • 
        
    • break stops the loop; continue skips to the next pass.
      • 
        
    • while repeats while a condition is true; do...while always runs once.
      • 
      
    
    
    
    
    
      
    Common mistakes
    
      
      
        
    • i <= arr.length, which runs one pass too many and reads undefined.
      • 
        
    • A while loop with nothing that makes its condition false: an infinite loop.
      • 
        
    • Declaring the total inside the loop, so it resets every pass.
      • 
        
    • Expecting map() to change the original array.
      •
