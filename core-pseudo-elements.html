Pseudo-elements

Pseudo-elements select a part of an element, like its first line or first letter, or add something that isn't in the HTML at all, like a decorative icon. They're written with two colons.

You'll be able to

  • Style part of an element with ::first-line, ::first-letter, ::marker and ::selection.
  • Combine a pseudo-class and a pseudo-element in one selector.
  • Generate content with ::before and ::after and the content property.
  • Use generated content for icons and shapes, and know when not to.
Read

What is a pseudo-element?

A pseudo-element acts as if you'd wrapped part of the content in a new element and styled that. It's written with two colons, which is how you tell it apart from a pseudo-class.

For example, to style the first line of a paragraph, you can't wrap it in a <span>: where the line ends depends on the screen width. ::first-line always finds it:

article p::first-line {
  font-size: 120%;
  font-weight: bold;
}

Others select different parts:

  • ::first-letter: the first letter, for a drop cap.
  • ::marker: a list item's bullet or number.
  • ::selection: text the visitor highlights.
  • ::placeholder: the hint text in an input.

Combining pseudo-classes and pseudo-elements

A selector can have both. To make only the first line of the first paragraph bold, put the pseudo-class first and the pseudo-element last:

article p:first-child::first-line {
  font-weight: bold;
}

Generating content with ::before and ::after

::before and ::after insert a new box at the start or end of an element's content, filled with whatever the content property says:

.box::before {
  content: "This should show before the other content. ";
}

Every ::before and ::after needs content, even an empty one, content: "", or it doesn't appear at all. They go inside the element, as its first and last child, so they don't work on empty elements like <img> or <input>.

Use them for decoration only. Text in content can't be selected or copied, and screen readers treat it inconsistently, so anything visitors need to read belongs in the HTML.

Generated content icons

A common use is a small decorative icon: .box::after { content: " ➥"; }.

Generated shapes

With empty content and display: block, a pseudo-element becomes a box you can size and colour: an underline bar, a coloured dot, a corner ribbon.

.box::before {
  content: "";
  display: block;
  width: 100px;
  height: 10px;
  background-color: rebeccapurple;
}

Key ideas

      
    
        
  • Pseudo-elements use two colons; pseudo-classes use one.
    • 
        
  • ::first-line, ::first-letter, ::marker and ::selection style parts of existing content.
    • 
        
  • Pseudo-class first, pseudo-element last: p:first-child::first-line.
    • 
        
  • ::before and ::after need a content property, even an empty one.
    • 
        
  • Generated content is for decoration; real information goes in the HTML.
    • 
      

    

    

      
Common mistakes

      
    
        
  • Forgetting content, so the pseudo-element never appears.
    • 
        
  • Adding ::before to an <img> or <input>.
    • 
        
  • Putting important text in content, where it can't be copied and may not be read aloud.
    • 
        
  • Writing the pseudo-element before the pseudo-class: p::first-line:first-child.
