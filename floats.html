Wrapping text around an image

A float moves an element to the left or right edge of its container, and lets the text that follows flow around it, like a photo in a magazine article. That's still the job floats do best:

.article img {
  float: left;
  width: 40%;
  margin: 0 1rem 1rem 0;   /* space between the photo and the text */
}

Give a floated element a width, or it shrinks to fit its content. And give it a margin on the side facing the text, so words don't press right against the image.

Sometimes the next part of the page should start below the float instead of wrapping beside it, like a new section heading. clear: both does that: the element moves down until it's past any floats above it.

Floats have one famous side effect. A floated element no longer counts toward its parent's height, so if everything inside a box is floated, the box collapses to nothing and its background and border disappear. Add display: flow-root to the parent and it contains its floats again.

Before Flexbox and Grid existed, floats were the only way to put boxes side by side, so whole page layouts were built from them, along with workarounds like the "clearfix" hack. You'll see that in older code and tutorials. For new layouts, use Flexbox or Grid, and keep floats for wrapping text.

Tip

On a phone, a floated image squeezes the text into a narrow strip. Use a media query to remove the float on small screens and let the image sit above the text.

Key ideas

  • A floated element needs a width, or it shrinks to fit its content.
  • Give floats a margin on the side facing the text so words don't touch the image.
  • clear: both makes an element start below any floats above it.
  • display: flow-root on the parent makes it contain its floats. Older code used a "clearfix" hack for this.
  • For side-by-side layout today, use Flexbox or Grid. Use floats for wrapping text.

Common mistakes

  • Building columns with floats, then fighting collapsed parents and uneven heights.
  • Forgetting that floats don't work on flex or grid items. The float is ignored.
  • On phones, a floated image squeezes the text into a narrow strip. Use a media query to remove the float on small screens.
  • Floating something to push it right, when margin-left: auto or justify-content would be simpler.
