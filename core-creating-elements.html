Creating and placing new nodes

So far you've changed elements that were already in the HTML. JavaScript can also build new ones, which is how a to-do list grows when you add an item, or how search results appear. It takes three steps:

const li = document.createElement("li");   // 1. make it
li.textContent = "Trail mix";               // 2. fill it
li.classList.add("item");
list.append(li);                            // 3. attach it

createElement() makes an element in memory. It isn't on the page yet, and it won't show up anywhere until you attach it to something that is. Forgetting that last step is the most common reason a new element never appears. append() adds it as the last child; prepend() adds it as the first. You'll also see the older appendChild(), which works the same way.

To take an element away, call remove() on it: li.remove().

An element can only be in one place at a time. Appending an element that's already on the page moves it rather than copying it. To make a copy, use cloneNode(true).

There's a shortcut you'll see a lot: setting innerHTML to a string of HTML. It's handy for building markup you wrote yourself. But never use it for text a visitor typed. If someone types <img src=x onerror=…>, innerHTML turns it into a real element, and the code inside runs. textContent shows exactly what was typed and never runs it.

Tip

After adding an item to a list, clear the input and put focus back in it with input.focus(), so people can type the next one straight away.

A dynamic shopping list

  


MDN's shopping list puts it all together. The HTML is a label, an input, a button and an empty list. The JavaScript, step by step:

    
    
      
  1. Store references to the list, the input and the button.
    2. 
      
  2. Add a listener to the button (or better, the form's submit).
    3. 
      
  3. In it, store the input's current value, then empty the input.
    4. 
      
  4. Create an <li>, a <span> and a <button>. Append the span and button to the list item, set the span's text to the value and the button's text to "Delete", then append the list item to the list.
    5. 
      
  5. Add a listener to the delete button that removes its list item.
    6. 
      
  6. Finally, call input.focus() so people can type the next item straight away.
    7. 
    

    
form.addEventListener("submit", (event) => {
  event.preventDefault();
  const myItem = input.value;
  input.value = "";

  const listItem = document.createElement("li");
  const listText = document.createElement("span");
  const listBtn = document.createElement("button");

  listItem.appendChild(listText);
  listText.textContent = myItem;
  listItem.appendChild(listBtn);
  listBtn.textContent = "Delete";
  list.appendChild(listItem);

  listBtn.addEventListener("click", () => {
    list.removeChild(listItem);
  });

  input.focus();
});

    An image gallery
    
  
    

    MDN's image gallery challenge builds a set of thumbnails from data. Clicking a thumbnail shows it large; a button darkens and lightens the big image.
    
    
    Start from data
    
    
    Instead of writing five <img> elements in the HTML, keep the images in an array of objects. Each object has the file name and the alt text:
    
    
    const images = [
  { filename: "pic1.jpg", alt: "Closeup of a human eye" },
  { filename: "pic2.jpg", alt: "Rock that looks like a wave" },
  // …
];
    
    
    Looping through the images
    
    
    Loop through the array. For each item, create an <img>, set its src and alt, and append it to the thumbnail bar:
    
    
    for (const image of images) {
  const newImage = document.createElement("img");
  newImage.src = `images/${image.filename}`;
  newImage.alt = image.alt;
  newImage.tabIndex = 0;
  thumbBar.appendChild(newImage);

  newImage.addEventListener("click", updateDisplayedImage);
  newImage.addEventListener("keydown", (e) => {
    if (e.code === "Enter") updateDisplayedImage(e);
  });
}

function updateDisplayedImage(e) {
  displayedImage.src = e.target.src;
  displayedImage.alt = e.target.alt;
}
    
    
    Images can't normally be focused, so tabIndex = 0 puts each one in the tab order, and the keydown listener lets keyboard users press Enter to choose it. (In your own work a <button> around each image gets you both for free.)
    
    
    The darken/lighten button
    
    
    The button's listener checks its own class. If it's dark, it switches to light, changes its text to "Lighten" and shows a translucent black overlay; otherwise it does the reverse. classList.toggle() is a compact way to flip a class on and off.

    Key ideas
    
      
      
        
    • Three steps: createElement() to make it, fill it in, then appendChild() or append() to attach it.
      • 
        
    • A created element isn't on the page until it's attached to something that is.
      • 
        
    • remove() takes an element out; appending one that's already on the page moves it.
      • 
        
    • Use textContent for anything a visitor typed, never innerHTML.
      • 
        
    • Keep repeated content in an array of objects and build the elements in a loop.
      • 
      
    
    
    
    
    
      
    Common mistakes
    
      
      
        
    • Creating an element and never attaching it.
      • 
        
    • Using innerHTML with user input, which can run code.
      • 
        
    • Adding listeners to elements before they've been created.
      • 
        
    • Clickable images or divs with no keyboard support.
