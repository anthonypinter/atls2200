Fluid Sizing

Media queries change things in jumps. clamp(), min(), max() and calc() let sizes change smoothly with the screen, inside limits you set, often with no media query at all.

You'll be able to

  • Make text and spacing grow smoothly with clamp().
  • Set upper and lower limits with min() and max().
  • Mix units with calc().

Sizes that grow smoothly

Media queries change things in jumps: two columns, then suddenly three. For sizes like headings and padding, a smooth change often looks better. CSS has four functions that do math with sizes, so a value can grow with the screen inside limits you set.

clamp() takes three values, always in this order: a minimum, a preferred value and a maximum.

h1 {
  font-size: clamp(1.75rem, 1rem + 3vw, 3.5rem);
}

The preferred value, 1rem + 3vw, grows as the window widens. clamp() keeps it between 28px and 56px, so the heading is never tiny on a phone or enormous on a big monitor. One line replaces several media queries. Mixing in rem also means the heading still grows when someone zooms in.

min() and max() pick one of their values. width: min(100%, 600px) uses whichever is smaller, so the box fills the screen on phones but never grows past 600px. It works like max-width. max() sets a floor instead. The names feel backwards at first: min() sets an upper limit.

calc() mixes units: calc(100% - 2rem) means "the full width, minus 32px." Inside clamp(), min() and max() you can do math without writing calc().

Watch out

calc(100%-2rem) is silently ignored. The + and - in calc() need a space on each side: calc(100% - 2rem).

Key ideas

  • clamp(1.75rem, 1rem + 3vw, 3.5rem) means: grow with the window, but stay between 28px and 56px.
  • calc() mixes units: calc(100% - 2rem) is "full width, minus 32px." Inside clamp(), min() and max() you can do math without writing calc.
  • min() sets an upper limit (like max-width), max() sets a lower limit (like min-width). The names feel backwards at first.
  • These work anywhere a length works: font sizes, widths, padding, gap and grid tracks.

Common mistakes

  • Leaving out the spaces: calc(100%-2rem) is ignored. The + and - need a space on each side.
  • Sizing text in vw alone. It's tiny on phones, huge on big monitors, and doesn't grow when people zoom.
  • Putting the values in the wrong order. clamp() is always min, preferred, max.
  • Using vw for widths inside a page that has a scrollbar. 100vw includes the scrollbar, so it causes sideways scrolling. Use 100%.
