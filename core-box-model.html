The Box Model

Everything on a web page is a box: headings, paragraphs, links, even a single word in bold. How big each box is, and how much space it takes up, follows a set of rules called the box model.

  • Name the four parts of a box and calculate its size in the standard and alternative box models.
  • Use margin, border and padding shorthands, and predict margin collapsing.
  • Use display: inline-block to give inline elements a usable size.

Block and inline boxes

Boxes come in two main kinds, and the kind decides how a box behaves in the page's flow:

  • A block box starts on a new line, stretches to fill the width of its container, and respects width, height, padding and margin. Headings, paragraphs and <div>s are block by default.
  • An inline box flows within a line of text. It doesn't start a new line, and width and height don't apply. <a>, <span>, <em> and <strong> are inline by default.

Inner and outer display types

The display property actually sets two things. The outer display type decides how the box behaves among its neighbours: block or inline. The inner display type decides how the box lays out its own children. Normally the children just flow, but display: flex makes them a flexbox layout (Week 5).

So display: flex means "block on the outside, flex on the inside", and display: inline-flex means "inline on the outside, flex on the inside".

What is the CSS box model?

Parts of a box

Every block box has four layers, from the inside out:

  • Content: the text or image itself, sized with width and height.
  • Padding: space between the content and the border. It's inside the box, so it shows the background.
  • Border: the line around the padding.
  • Margin: space outside the border that pushes other boxes away. It's always transparent.

The standard CSS box model

By default, width and height set only the content; padding and border are added on top. Margin isn't counted in the box's size, but it does take up space.

.box {
  width: 350px;
  height: 150px;
  margin: 10px;
  padding: 25px;
  border: 5px solid black;
}  /* the box is 350 + 25 + 25 + 5 + 5 = 410px wide, and 210px tall */

The alternative CSS box model

With box-sizing: border-box, width sets the whole visible box, padding and border included, and the content shrinks to fit. That's much easier to plan with. Many developers switch every element to it at the top of their stylesheet:

html {
  box-sizing: border-box;
}
*, *::before, *::after {
  box-sizing: inherit;
}

Use DevTools

Select an element and open the Computed or Layout tab: it draws the box model with the size of every layer. When a box is bigger than you expected, look there first.

Margins, padding, and borders

Each of the three has a shorthand that sets all four sides, and longhands for one side at a time: margin-top, padding-left, border-bottom. Shorthands with several values go clockwise from the top: margin: 10px 20px is 10px top and bottom, 20px left and right.

Margin

Margin pushes other boxes away. It can be negative, which pulls things closer or makes boxes overlap. margin: 0 auto on a block with a width centres it: the left and right margins share the leftover space.

Margin collapsing: when the bottom margin of one block meets the top margin of the next, they don't add up. They collapse into the larger of the two. A heading with margin-bottom: 30px above a paragraph with margin-top: 20px leaves 30px between them, not 50px.

Borders

border: 2px solid teal sets width, style and colour on all four sides. Each side and each part has a longhand: border-top, border-width, border-left-color and so on. Without a style (solid, dashed, dotted…) there's no border at all.

Padding

Padding is the space inside the border. Unlike margin, it can't be negative. Use it to stop text from touching the edge of a coloured box.

The box model and inline boxes

Inline boxes follow only part of the box model. width and height are ignored. Padding, borders and margins do apply, but only left and right ones push other content away: top and bottom padding and borders spread over the lines above and below without moving them.

Read

Using display: inline-block

display: inline-block is the middle ground. The box sits in a line of text like a word, doesn't force a new line, but respects width, height and padding, pushing other content out of the way. It's perfect for giving links a bigger, clickable area.

Key ideas

  • Block boxes start a new line and fill their container; inline boxes flow in the text and ignore width and height.
  • display sets an outer type (block or inline) and an inner type (normal flow, flex, grid).
  • Standard box model: width sets the content; padding and border are added on top.
  • box-sizing: border-box makes width include padding and border.
  • Touching vertical margins collapse into the larger one.
  • inline-block flows like text but respects width, height and padding.

Common mistakes

  • Setting width on a link or span and wondering why nothing happens.
  • Forgetting that padding and border make a content-box element wider than its width.
  • Expecting 30px + 20px margins to make a 50px gap.
  • Using padding where you meant margin: padding fills with the background colour.
  • A border with a width and colour but no style, so it doesn't appear.
