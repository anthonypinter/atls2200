Layout · CSS Grid

CSS Grid Playground

Grid controls rows and columns at the same time. Define the columns on the container, and items fill the cells in order unless you tell one to span more space.

You'll be able to

  • Define a grid's columns with grid-template-columns, fr and repeat().
  • Make an item span several columns or rows.
  • Build a responsive card grid with auto-fit and minmax(), without media queries.
Read

Rows and columns at the same time

Flexbox lines items up in one direction. Grid handles two at once: you define columns (and rows, if you need them) on the container, and the items fill the cells in order.

.gallery {
  display: grid;
  grid-template-columns: 2fr 1fr 1fr;
  gap: 16px;
}

That makes three columns. The fr unit means "a fraction of the leftover space", so the first column is twice as wide as each of the others, whatever the container's width. repeat(3, 1fr) is a shortcut for three equal columns. Gap adds space between cells, just as it does in Flexbox.

Items fill the grid left to right, top to bottom, one per cell. Any item can take up more room:

.featured {
  grid-column: span 2;   /* two columns wide */
  grid-row: span 2;      /* two rows tall */
}

The other items flow around it. Spanning rows as well as columns is something only Grid can do.

The most useful line of Grid makes a card gallery that adapts to any screen with no media queries at all:

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
}

Read it as: "fit as many columns as you can, each at least 220px wide, and share any extra space equally." On a phone you get one column, on a laptop four.

Watch out

Like Flexbox, display: grid and grid-template-columns go on the container, not on the items. The items only need rules when one of them should span or move.

Key ideas

  • fr means "a fraction of the leftover space." 1fr 2fr makes the second column twice as wide.
  • repeat(3, 1fr) is shorthand for 1fr 1fr 1fr.
  • grid-column: span 2 makes an item take up two columns. Other items flow around it.
  • repeat(auto-fit, minmax(120px, 1fr)) makes a responsive grid with no media queries. Resize the window to see it.

Common mistakes

  • Setting grid-template-columns on the items instead of the container.
  • Spanning more columns than the grid has, which creates extra implicit columns.
  • Using fixed px columns everywhere, so the layout overflows on phones.
  • Mixing up justify-items (horizontal, inside each cell) with justify-content (the whole grid).
