Embeds & iframes

An <iframe> is a window in your page that shows another web page. It's how you put a YouTube video, a Google Map or a CodePen demo on your site without hosting it yourself.

You'll be able to

  • Embed a YouTube video or a Google Map with an iframe.
  • Give an iframe a title, make it responsive, and lazy-load it.
  • Explain why your CSS doesn't affect what's inside an iframe.

A window into another page

An iframe puts a whole separate web page inside yours. It's how you show a YouTube video, a Google Map or a CodePen demo without hosting any of it. The service gives you the code to embed, usually from a Share or Embed button:

<iframe src="https://www.youtube.com/embed/VIDEO_ID"
        title="Hiking the Mesa Trail, a 3-minute tour"
        loading="lazy"></iframe>

Three attributes are worth adding to whatever you paste:

  • title says what's inside. A screen reader announces it, so people can decide whether to go in.
  • loading="lazy" waits until the visitor scrolls near it. A YouTube player downloads close to 1 MB before anyone presses play, so this matters.
  • Responsive sizing. Embed code usually arrives with width="560" height="315", which sticks out of the page on a phone. Instead, set it in CSS:
iframe {
  width: 100%;
  height: auto;
  aspect-ratio: 16 / 9;
}

Because an iframe holds a separate document, your CSS can't reach inside it, and its CSS can't leak out. You can size and position the frame, but you can't restyle the video player or the map within it.

Watch out

The src must be the embed address, like youtube.com/embed/…, not the page you'd visit, like youtube.com/watch?v=…. The ordinary page refuses to load inside a frame.

    When embedding is refused
    Many sites, including most banks, social sites and Google Search, tell browsers not to show them inside iframes. You'll see a blank box or "refused to connect." Link to them instead.

    Key ideas
    
      
      
        
    • Give every iframe a title that says what's in it. Screen readers announce it so people can decide whether to go in.
      • 
        
    • To make an embed responsive, set width: 100%, height: auto and an aspect-ratio that matches the content, like 16 / 9 for video.
      • 
        
    • loading="lazy" waits until the visitor scrolls near the embed. A YouTube player downloads close to 1 MB before anyone presses play.
      • 
        
    • Each embed is a full web page with its own scripts and tracking. Use them where they add real value.
      • 
      
    
    
    
    
    
      
    Common mistakes
    
      
      
        
    • Pasting the code with width="560" and never testing on a phone, so the video sticks out of the page.
      • 
        
    • Pasting the page address (youtube.com/watch?v=…) as the src. It must be the embed address (youtube.com/embed/…).
      • 
        
    • Trying to style what's inside the iframe with your own CSS.
      • 
        
    • Embedding a video you could simply host yourself with <video>, or vice versa: uploading a huge video file to GitHub Pages instead of YouTube.
