Images & Alt Text

The alt attribute is what people hear when they can't see an image. Pick alt text for each image in this article, then switch to the screen reader view to hear the result.

You'll be able to

  • Add an image with src, alt, width and height.
  • Write alt text that describes what an image means in context.
  • Caption an image with figure and figcaption.
Read

Every image needs a text version

Adding an image takes one element: <img>. It's an empty element, so there's no closing tag, and everything goes in attributes:

<img src="photos/royal-arch.jpg"
     alt="Hikers standing under the sandstone arch at the top of the trail"
     width="1200" height="800">

src is the path to the file. width and height tell the browser the image's shape before it downloads, so the page doesn't jump around while it loads. CSS can still resize it.

The most important attribute is alt. Alt text is what a screen reader reads aloud, what search engines index, and what appears if the image fails to load. Good alt text describes what the image means on this page, not every detail. Ask yourself: if I were reading this page aloud to a friend, what would I say about this picture?

  • A photo in a trail report: describe what it shows that matters to the report.
  • An image inside a link, like a logo linking home: describe where the link goes, "Boulder Trail Club home".
  • A purely decorative image, like a background flourish: use an empty alt="" so screen readers skip it. Don't leave alt out, or many screen readers read the file name instead.

When an image needs a visible caption, wrap it in <figure> and put the caption in <figcaption>. The browser then knows the two belong together.

Tip

Don't start alt text with "Image of" or "Photo of". Screen readers already announce that it's an image, so the words just slow people down.

Captions

figure and figcaption

When an image needs a visible caption, wrap the image and its caption in a <figure> and put the caption in <figcaption>. That ties them together for screen readers and for CSS.

What a screen reader says

    

  

  
alt text vs caption
alt replaces the image for people who can't see it. A caption is visible to everyone and adds information, like who took the photo or when. Don't repeat the same words in both: a screen reader would read them twice.

Common mistakes

      
    
        
  • Starting with "Image of…". Screen readers already announce that it's an image.
    • 
        
  • Using the file name, like IMG_4031.jpg, as the alt text.
    • 
        
  • Missing alt completely. Many screen readers then read out the file name.
    • 
        
  • Wrong paths: src="images/photo.JPG" won't load photo.jpg on most servers, because file names are case-sensitive.
