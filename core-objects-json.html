Objects and JSON

An array is a list in order. An object groups related values under names, like everything you know about one trail. JSON is the same idea written as text, and it's how most data travels around the web.

You'll be able to

  • Create an object, and read and change its members with dot and bracket notation.
  • Write methods, and use this inside them.
  • Create many similar objects with a function or a constructor.
  • Read JSON's rules, and convert between JSON text and objects with JSON.parse() and JSON.stringify().
Read

Object basics

An object is a collection of related data and functionality, written as key: value pairs inside curly braces. Each pair is a member. A member whose value is data is a property; a member whose value is a function is a method.

const person = {
  name: ["Bob", "Smith"],
  age: 32,
  bio: function () {
    console.log(`${this.name[0]} ${this.name[1]} is ${this.age} years old.`);
  },
  introduceSelf() {
    console.log(`Hi! I'm ${this.name[0]}.`);
  },
};

introduceSelf() { … } is a shorter way to write introduceSelf: function () { … }. An object written out like this, with braces, is an object literal. Separate members with commas.

Read

Dot notation

To read a member, write the object's name, a dot, and the member's name. Call methods with parentheses:

person.age          // 32
person.name[0]      // "Bob"
person.bio();       // logs "Bob Smith is 32 years old."

Objects as object properties

A value can itself be an object. Then you chain dots, one step at a time:

const person = {
  name: { first: "Bob", last: "Smith" },
};
person.name.first   // "Bob"

Bracket notation

Square brackets with the key as a string do the same thing as a dot: person["age"] is person.age. You need brackets when the key is in a variable, because a dot always looks for a key with that exact name.

function logProperty(propertyName) {
  console.log(person[propertyName]);
}
logProperty("age");   // 32

    What is "this"?
    
  
    

    Inside a method, this means the object the method was called on. That's why bio() above uses this.age and not person.age: the same method will then work on any object that has it.

    Working with JSON
    
  
    

    What is JSON?
    
    
    JSON (JavaScript Object Notation) is a text format for structured data, based on JavaScript's object literal syntax. Servers send it, APIs return it, and config files are written in it. Because it's just text, any language can read it, but in JavaScript you first convert it into an object.
    
    
    JSON structure
    
    
    JSON looks like an object literal, and can contain strings, numbers, booleans, null, arrays and other objects:
    
    
    {
  "squadName": "Super hero squad",
  "formed": 2016,
  "active": true,
  "members": [
    { "name": "Molecule Man", "age": 29, "powers": ["Radiation resistance", "Turning tiny"] }
  ]
}
    
    
    Once parsed (say into superHeroes), you read it like any object: superHeroes.members[0].powers[1] is "Turning tiny".
    
    
    Arrays as JSON
    
    
    A JSON file doesn't have to start with {. An array, [ {…}, {…} ], is valid JSON too, and a common way to send a list of things.
    
    
    Other notes
    
    
      
      
    • JSON is purely data. It can't contain functions (methods) or comments.
      • 
      
    • Property names and strings must use double quotes. Single quotes are invalid.
      • 
      
    • No trailing comma after the last item.
      • 
      
    • One misplaced comma or colon breaks the whole file. A validator helps find it.
      •

    Converting between objects and text
    
  
    

    JSON arrives as a string. Two built-in methods convert it:
    
    
      
      
    • JSON.parse(text) turns JSON text into an object you can read with dots.
      • 
      
    • JSON.stringify(obj) turns an object into JSON text, ready to save or send.
      • 
    
    
    
    When you load JSON from a server with fetch(), the response's json() method does the parsing for you. You'll do that in Fetching Data.

    Key ideas
    
      
      
        
    • An object is a set of key: value members in braces. Data members are properties; function members are methods.
      • 
        
    • Read with a dot (hike.miles) or brackets (hike["miles"]). Use brackets when the key is in a variable.
      • 
        
    • Assign to change or add a member: hike.rating = 5;
      • 
        
    • Inside a method, this is the object it was called on. Constructors use this and are called with new.
      • 
        
    • JSON is text. JSON.parse(text) makes an object; JSON.stringify(obj) makes text.
      • 
      
    
    
    
    
    
      
    Common mistakes
    
      
      
        
    • hike.key when key is a variable. It looks for a key literally named "key". Use hike[key].
      • 
        
    • Single quotes, trailing commas or comments in JSON. Any one of them makes it fail to parse.
      • 
        
    • Using JSON text as if it were an object: text.members is undefined until you parse it.
      • 
        
    • Forgetting new when calling a constructor.
