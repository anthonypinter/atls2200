Display and Normal Flow

Before you write any layout CSS, the browser already has a plan for where every box goes: normal flow. Understanding it, and the ways CSS can override it, is the foundation for every layout you'll build.

You'll be able to

  • Describe normal flow: how block and inline boxes are placed by default.
  • Change an element's box type with display, and see which properties it then obeys.
  • Name the main ways CSS overrides normal flow: display, floats, positioning, flexbox and grid.
  • Hide content with display: none, visibility: hidden or opacity: 0, and know the difference.

Normal layout flow

Normal flow is how the browser lays out a page when you haven't told it otherwise. It puts elements on the page in the same order as your HTML, one after another. Because of that, a well-structured HTML document is already readable before any layout CSS. Start from good HTML and change the flow only where you need to.

How are elements laid out by default?

Each element's content sits inside its padding, border and margin: the box model from the last lesson. Then:

  • Block boxes stack one below another, in the block direction (top to bottom for English). Each fills the width of its parent, and is as tall as its content. Their vertical margins collapse where they touch.
  • Inline boxes sit side by side in the inline direction (left to right for English), like words. When a line runs out of room, they wrap onto the next line.

    Overriding normal flow

    Normal flow can't put things side by side in columns, or pin a header to the top of the screen. For that, CSS has several layout tools, each covered in a later week:

    • The display property: besides block and inline, display: flex and display: grid switch on whole layout systems for an element's children.
    • Floats: float: left moves a box to one side and lets text wrap around it, like an image in a magazine.
    • Positioning: position moves a box from where normal flow put it, or pins it to the screen.
    • Flexbox (Week 5): lays items out in one direction, a row or a column, and shares space between them.
    • Grid (Week 5): lays items out in rows and columns at once.
    • Responsive design (Week 6): changes the layout to suit the screen size.

    Other layout techniques

    Two more exist but are less common: table layout (display: table, from before flexbox existed) and multi-column layout (column-count: 3), which flows text into columns like a newspaper.

    Key ideas
    
      
      
        
    • Normal flow places elements in source order: blocks stack, inline boxes sit side by side and wrap.
      • 
        
    • Good HTML in normal flow is already readable; layout CSS changes it only where needed.
      • 
        
    • display chooses block, inline or inline-block, and switches on flex and grid.
      • 
        
    • Floats, positioning, flexbox and grid all override normal flow in different ways.
      • 
        
    • display: none removes the box; visibility: hidden and opacity: 0 keep its space.
      • 
      
    
    
    
    
    
      
    Common mistakes
    
      
      
        
    • Setting width on an inline element and wondering why it's ignored.
      • 
        
    • Reaching for floats or positioning to build a whole layout: use flexbox or grid.
      • 
        
    • Changing the visual order so it no longer matches the HTML order, confusing keyboard and screen reader users.
      • 
        
    • Hiding with opacity: 0 when you meant to remove: it's still clickable and still read aloud.
