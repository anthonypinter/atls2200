What you've covered

This part was about how the browser decides what each element looks like: which rules match, which one wins, and how boxes, colors and text are sized.

  • How CSS Is Applied: A rule is a selector plus declarations, and one missing semicolon can break the next line.
  • Selectors & Specificity: A space means inside, > means direct child, and IDs outrank classes, which outrank elements.
  • Pseudo-classes & States: Style :hover and :focus-visible together, and use :nth-child for patterns.
  • Pseudo-elements: ::before and ::after add decoration, and need a content property.
  • Cascade & Inheritance: Text properties inherit, box properties don't, and later rules win ties.
  • The Box Model: Padding and border add to the width unless box-sizing is border-box.
  • Display Types: Block elements stack, inline elements flow, and inline-block flows but accepts a width.
  • Sizing Items: width: 100% with a max-width adapts; min-height lets boxes grow.
  • Overflow: Content that doesn't fit spills out; overflow and overflow-wrap control it.
  • Colors & Units: rem for text, % or max-width for widths, and a fourth value for transparency.
  • CSS Variables: Store a value once on :root, use it with var(), and redefine it to theme a part of the page.
  • Backgrounds & Borders: Gradients are background images, and border-radius: 50% makes a circle.
  • Shadows & Filters: Soft, semi-transparent shadows that fall downward look natural.
  • Typography: Keep lines 45–75 characters long, with a unitless line-height around 1.5.
  • Web Fonts: Quote font names with spaces, end every list with a generic family, and use font-display: swap.
