CSS Variables

A CSS variable (custom property) stores a value once so you can reuse it everywhere. Change one variable here and every part of the site that uses it updates at once.

You'll be able to

  • Define a CSS variable on :root and use it with var().
  • Redefine a variable on one element to change just that part of the page.
  • Build a simple dark theme by redefining a few color variables.
Read

Store a value once, use it everywhere

Say your site's brand color is teal, and it appears in forty places in your stylesheet: buttons, links, borders, headings. Then the client asks for a darker teal. With a CSS variable, that's a one-line change:

:root {
  --brand: #0b6b5e;
  --space: 16px;
}
.btn {
  background: var(--brand);
  padding: var(--space);
}

You define a variable with two dashes at the start of its name, and use it with var(). Defining variables on :root, which is the <html> element, makes them available to the whole page.

Variables follow the same inheritance as text styles: an element sees the value defined on itself or its nearest ancestor. That makes them powerful. Redefine --brand on one featured card, and only that card and its children see the new color, while everything else keeps the original.

The same idea gives you a dark theme almost for free. Define your colors as variables, then redefine just those variables for dark mode:

@media (prefers-color-scheme: dark) {
  :root { --bg: #10131d; --text: #e7e9f3; }
}

If a variable might not be defined, give a fallback: var(--sale, crimson) uses crimson when there's no --sale.

Watch out

color: --brand; does nothing. You always need var() to read a variable. And names are case-sensitive, so --Brand is a different variable.

Key ideas

  • Define variables with two dashes, usually on :root so the whole page can use them: --brand: #0b6b5e;
  • Use them with var(): color: var(--brand);
  • Variables inherit. Redefine one on a single element, and only that element and its children see the new value.
  • Give a fallback for when a variable isn't defined: var(--sale, crimson).
  • A dark theme can be as simple as redefining a few color variables.

Common mistakes

  • Forgetting var(): color: --brand; does nothing.
  • Only one dash, or a typo in the name. Variable names are case-sensitive.
  • Doing math without calc(): use calc(var(--space) * 2).
  • Defining the variable on an element that isn't a parent of where you use it.
