Tables are for data

A table is the right element when your data has rows and columns that both mean something, like a hike schedule or a comparison of trails. Each row is a <tr>, and each row holds cells: <th> for headers, <td> for data.

<table>
  <caption>Boulder-area trails</caption>
  <thead>
    <tr><th scope="col">Trail</th><th scope="col">Miles</th></tr>
  </thead>
  <tbody>
    <tr><th scope="row">Mesa</th><td>6.7</td></tr>
  </tbody>
</table>

Every piece of that markup helps someone. The <caption> is the table's title. <thead> and <tbody> group the header row and the data. And scope tells a screen reader which cells a header labels. Without it, a listener moving through the table hears "6.7" and has to remember which trail and which column that was. With it, they hear "Mesa, Miles: 6.7".

Sometimes a cell needs to stretch: colspan="2" makes it two columns wide, and rowspan="2" makes it two rows tall. Every row still has to add up to the same number of columns, or the cells after it shift out of line.

Tables used to be how whole pages were laid out, because there was nothing better. Now there is. If your "rows and columns" are really a grid of cards or a page layout, use Flexbox or CSS Grid, and keep tables for data.

Tip

Wide tables don't fit on phones. Wrap the table in a <div> with overflow-x: auto so it scrolls sideways instead of stretching the whole page.

    Key ideas

    • Structure: <table> holds rows (<tr>), and rows hold cells (<td> for data, <th> for headers).
    • Group rows with <thead> and <tbody>.
    • scope="col" or scope="row" tells screen readers which cells a header labels.
    • colspan and rowspan merge cells. Every row must still add up to the same number of columns.
    • Wrap wide tables in a container with overflow-x: auto so they scroll on phones instead of breaking the page.

    Common mistakes

    • Using a table to lay out a page or a grid of cards. Use Flexbox or Grid.
    • Making header cells bold <td>s instead of real <th>s.
    • A different number of cells in each row, which shifts columns out of line.
    • Putting a border on the table only and expecting the cells to get one too.
