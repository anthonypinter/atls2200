What you've covered

This part connected JavaScript to the page: finding elements, reacting to what people do, building new elements, and loading data from a server.

  • Selecting & Changing Elements: querySelector finds elements with CSS selectors; textContent and classList change them.
  • Events: addEventListener runs a function when something happens; preventDefault stops the browser's own action; events bubble.
  • Creating & Removing Elements: createElement, then fill it, then append it. Use textContent for anything a person typed.
  • Fetching Data: fetch returns a promise; await it, check response.ok, parse the JSON, and catch errors.
