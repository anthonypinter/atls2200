HTML Images

One empty element, <img>, puts a picture on the page. Getting it right means a path that works, a size the browser knows in advance, and alt text for the people who can't see it.

You'll be able to

  • Add an image with src, alt, width and height.
  • Fix a broken image path.
  • Write alt text that fits the image's job on the page.
  • Caption an image with <figure> and <figcaption>.
  • Know when an image belongs in CSS instead, and when you're allowed to use one.
Read

How do we put an image on a webpage?

<img> is an empty element: no closing tag, and everything goes in attributes. The one it can't do without is src, the path to the image file:

<img src="images/royal-arch.jpg" alt="Hikers under a sandstone arch">

src works like a link's href. A relative path starts from the folder the current page is in, ../ goes up one folder, and file names must match exactly: on most web servers Arch.JPG and arch.jpg are different files. You can also point at an absolute URL, but only use images you have permission to use, and don't "hotlink" to files on someone else's server.

Alternative text

The alt attribute holds a text version of the image. It's what a screen reader reads aloud, what search engines index, and what appears when the image fails to load. Good alt text describes what the image does on this page, not every detail. Ask: if I read this page aloud to a friend, what would I say about this picture?

  • Content: a photo in a trail report. Describe what matters to the report.
  • Link: a logo linking home. Describe where the link goes: "Boulder Trail Club home".
  • Text in an image: put the same words in the alt. (Better still, use real text.)
  • Decoration: a flourish or divider. Use an empty alt="" so screen readers skip it. Don't leave alt out, or many screen readers read the file name instead.

Tip

Don't start alt text with "Image of". Screen readers already announce that it's an image.

Width and height

Set width and height to the image's real size in pixels, with no units:

<img src="images/longs-peak.jpg" alt="…" width="640" height="300">

The browser draws the page before the image arrives. Without the dimensions it reserves no space, then shoves everything below down when the file lands, often just as you go to click something. With them, it holds an empty box of the right shape. CSS can still resize the image, and it keeps that shape.

Don't use the attributes to shrink a huge photo, though: the browser still downloads every byte. Resize the file itself.

Image titles

  

    
Like links, images can take a title attribute, which shows as a tooltip when you hover. It's not a good place for information: touch screens and keyboards can't hover, and many screen readers ignore it. If something matters, put it in the alt text or a visible caption.

Annotating images with figures and figure captions

  

    
When an image needs a visible caption, wrap the image and caption in <figure> and put the caption in <figcaption>. That ties them together, for screen readers and for CSS. A figure doesn't have to hold an image: a code listing, a chart, a quote or a video can be a figure too.

    
Alt text and caption do different jobs. The alt replaces the image for people who can't see it. The caption is for everyone and adds information, like who took the photo. Don't repeat the same words in both, or a screen reader reads them twice.

CSS background images

  

    
CSS can also put images on a page, with background-image. Those images are pure decoration: they have no alt text, screen readers don't know they exist, and they don't print by default.

    
So the rule is simple: if the image means something in your content, use <img>. If it's only decoration, a background image is fine. You'll use them in Week 4.

Image licensing

  

    
Finding an image online doesn't mean you can use it. Images on your site should be:

    
    
      
  • Yours: you made it, or you own the rights.
    • 
      
  • Permission granted: the owner said yes, ideally in writing.
    • 
      
  • Openly licensed: for example under a Creative Commons licence or in the public domain. Follow the licence's terms, which often means crediting the creator.
    • 
    

    
Search engines and sites like Wikimedia Commons, Unsplash and Openverse let you filter by licence. When in doubt, take your own photo.

Key ideas

      
    
        
  • <img> is empty: src says where the file is, and paths work like links.
    • 
        
  • File names are case-sensitive on most servers.
    • 
        
  • Alt text describes what the image does on the page. Decoration gets alt="".
    • 
        
  • width and height stop the page jumping while images load.
    • 
        
  • <figure> and <figcaption> tie a caption to its image.
    • 
        
  • Meaningful images go in HTML; decorative ones can go in CSS.
    • 
      

    

    

      
Common mistakes

      
    
        
  • A path relative to the wrong folder, or Photo.JPG for photo.jpg.
    • 
        
  • Missing alt, so screen readers read IMG_4031.jpg aloud.
    • 
        
  • Alt text that starts with "Image of", or repeats the caption word for word.
    • 
        
  • Putting important information in title.
    • 
        
  • Using any image you found on a search engine.
