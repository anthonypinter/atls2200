Variables & Data Types

A variable is a labeled box that holds a value. let boxes can be refilled; const boxes can't. Step through the code and watch the boxes change.

You'll be able to

  • Store values in variables with const and let, and choose between them.
  • Name variables so they're valid and easy to read.
  • Identify the main data types and check a value's type with typeof.
Read

Giving values a name

A program needs to remember things: a player's score, a visitor's name, whether the menu is open. A variable is a name that holds a value, so you can use it later.

const trail = "Mesa Trail";
let miles = 6.7;
miles = miles + 1;

There are two ways to make one. const creates a variable that can't be given a new value. let creates one that can. Use const by default, and let only when the value really needs to change, like a counter or a score. That way, anyone reading your code knows which values move.

You declare a variable once, with let or const. After that, use just its name. Writing let miles a second time is an error.

Names can contain letters, numbers, _ and $, but can't start with a number or contain spaces. JavaScript developers write multi-word names in camelCase: trailName, isOpen. Names are case-sensitive, so score and Score are two different variables.

Every value has a type. The main ones are numbers (42, 6.7), strings of text in quotes ("Mesa"), and booleans, which are just true or false. Arrays and objects hold groups of values, and you'll meet them soon. typeof tells you a value's type.

Watch out

Quotes always make a string. "42" is text that happens to look like a number, and that difference causes surprising bugs, as the next lesson shows.

    Key ideas
    
      
      
        
    • Use const when you can, and let when you have to. Use let only when the value needs to change, such as a score or a counter.
      • 
        
    • Declare a variable once with let or const, then use just its name afterward.
      • 
        
    • The main types: number (42, 3.4), string ("text"), boolean (true/false), plus arrays and objects for groups of values.
      • 
        
    • JavaScript is dynamically typed: the value decides the type, and a let variable can hold a different type later.
      • 
        
    • A const array or object can still have its contents changed. What can't change is which array or object the name refers to.
      • 
      
    
    
    
    
    
      
    Common mistakes
    
      
      
        
    • Using var. It's the old way, with confusing rules. MDN says there's no reason to use it in new code.
      • 
        
    • Writing let again when updating a value: let score = 1; then let score = 2; is an error.
      • 
        
    • Numbers in quotes: "5" + 5 gives "55", not 10.
      • 
        
    • Mixing up case: myAge and myage are two different variables.
