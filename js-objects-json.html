Objects & JSON

An object groups related values under named keys, such as a trail's name, length and location. JSON is the same idea written as text, and it's how most data travels between websites and servers.

You'll be able to

  • Create an object and read its values with dots and brackets.
  • Navigate nested objects and arrays one step at a time.
  • Convert between objects and JSON text with JSON.parse and JSON.stringify.
Read

Grouping values under names

An array is a list in order. An object groups related values under names, called keys, like everything you know about one trail:

const hike = {
  name: "Royal Arch",
  miles: 3.4,
  dogs: true,
  tags: ["steep", "views"],
};
hike.name          // "Royal Arch"
hike["miles"]      // 3.4
hike.tags[1]       // "views"

Read a value with a dot and the key's name. Square brackets with the key as a string do the same thing, and you need them when the key is stored in a variable: if key holds "miles", then hike[key] works but hike.key looks for a key literally named "key".

Values can be anything, including arrays and other objects. Real data is often nested several levels deep, so read it one step at a time: trails[0].tags[1] means the first trail, then its tags, then the second tag. To add or change a value, assign it: hike.rating = 5.

JSON is the same idea written as plain text. It's how most data travels between websites and servers. It has stricter rules than JavaScript: keys need double quotes, strings use double quotes too, and there are no trailing commas or comments.

Because JSON is text, you convert it before using it. JSON.parse(text) turns JSON text into an object you can read with dots. JSON.stringify(obj) turns an object back into text, ready to save or send.

Watch out

One missing comma or a single quote makes JSON invalid, and JSON.parse() throws an error. If the error mentions an unexpected token, check the JSON text first.

Dot or brackets?

When the key is stored in a variable (for example, chosen from a dropdown), you have to use square brackets. A dot always looks for a key with that exact name.

    Key ideas
    
      
      
        
    • An object is a set of key: value pairs in curly braces. Values can be anything, including arrays, other objects and functions (methods).
      • 
        
    • Read values with a dot (hike.miles) or brackets (hike["miles"]). Use brackets when the key is in a variable.
      • 
        
    • Chain through nested data one step at a time: squad.members[1].powers[2].
      • 
        
    • Add or change a value just by assigning it: hike.rating = 5;
      • 
        
    • JSON is text. JSON.parse(text) makes an object from it; JSON.stringify(obj) makes text from an object.
      • 
        
    • fetch() responses have a .json() method that parses for you.
      • 
      
    
    
    
    
    
      
    Common mistakes
    
      
      
        
    • hike.key when key is a variable. It looks for a key literally named "key". Use hike[key].
      • 
        
    • Single quotes, trailing commas or comments in a .json file. Any one of them makes the whole file fail to parse.
      • 
        
    • Using JSON text as if it were an object: text.members is undefined until you parse it.
      • 
        
    • Forgetting the commas between properties in an object literal.
