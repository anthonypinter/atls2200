Web Fonts

You can only count on a handful of fonts being installed on every computer. Web fonts are downloaded with your page, so every visitor sees the type you chose, as long as you load them carefully.

Web fonts

A web font is a font file the browser downloads along with your CSS. You declare it with an @font-face rule, which gives the font a name and says where the file is, and then use that name like any other:

@font-face {
  font-family: "Trail Sans";
  src: url("fonts/trail-sans.woff2") format("woff2");
}

html {
  font-family: "Trail Sans", "Trebuchet MS", sans-serif;
}

Two things to know:

  • Use WOFF2. It's the compressed web font format every current browser supports. You don't need older formats like TTF or EOT.
  • Fonts have licences. Fonts are software. A font installed on your computer isn't necessarily licensed for use on the web; check before you upload one. Free fonts from Google Fonts or Font Squirrel are licensed for the web.

A web font is a download, and downloads take time or fail. Until it arrives, the browser uses the next font in your stack, so pick a fallback that's similar.

Adding your own web fonts

Finding fonts

Free fonts: Google Fonts, Font Squirrel, and the open-source fonts many foundries publish. Paid fonts come from foundries and services like MyFonts. Read the licence either way.

Generating the required code

If you have a font file in another format, a converter like Transfonter turns it into WOFF2 and writes the @font-face rules for you. Download only the weights and styles you'll use.

Implementing the code in your demo

  1. Put the .woff2 files in a fonts/ folder in your project.
  2. Add an @font-face rule for each file at the top of your stylesheet. The src path is relative to the CSS file.
  3. Use the name in font-family, with fallbacks.
@font-face {
  font-family: "Zantroke";
  src: url("fonts/zantroke-webfont.woff2") format("woff2");
  font-weight: normal;
  font-style: normal;
  font-display: swap;
}

h1 {
  font-family: "Zantroke", serif;
}

Using an online font service

Services like Google Fonts host the files and write the CSS for you. Choose a font and its weights, copy the <link> tags they give you into your <head> (above your own stylesheet), then use the name in font-family. It's the quickest way to start, though the visitor's browser now contacts another company's server, and the page depends on it being up.

The easy way: Google Fonts
  1. Find a font at fonts.google.com and choose the weights you need.
  2. Copy the <link> tags it gives you into your page's <head>, above your own stylesheet.
  3. Use the font in CSS with font-family, followed by fallbacks.
Self-hosting with @font-face
  1. Put the .woff2 files in a fonts/ folder in your project.
  2. Add an @font-face rule naming the font and pointing to the file.
  3. Use that name in font-family like any other font.

@font-face in more detail

  • font-family: the name you'll refer to the font by. It can be anything, but must match exactly where you use it.
  • src: the path to the file, with format("woff2") so the browser can skip formats it doesn't support. List several files, comma-separated, and it uses the first it can.
  • font-weight and font-style: which weight and style this file contains. To use regular and bold, write two @font-face rules with the same font-family and different font-weight. If you ask for a bold you didn't load, the browser fakes one by smearing the regular letters.
  • font-display: what to show while the file downloads. swap shows the fallback straight away and swaps when the font arrives; it's the usual choice.

Variable fonts and other descriptors

A variable font packs a whole range of weights (and sometimes other qualities) into a single file. Its @font-face gives a range, like font-weight: 300 1000, and then any weight in between works. Extra design axes are set with font-variation-settings. Two more descriptors you may meet: font-stretch (condensed to expanded) and unicode-range (download this file only if the page uses these characters).

Common mistakes

      
    
        
  • A font-family name that doesn't exactly match the @font-face name: it fails silently.
    • 
        
  • A src path relative to the HTML page instead of the CSS file.
    • 
        
  • Using font-weight: 700 after loading only 400, so the browser fakes a bold.
    • 
        
  • Loading every weight a family offers "just in case".
    • 
        
  • Uploading a font you don't have a web licence for.
