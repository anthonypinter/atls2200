Selecting & Changing Elements

The browser turns your HTML into a tree of objects called the DOM (Document Object Model). JavaScript finds elements in that tree with the same selectors you use in CSS, then changes them.

    Key ideas
    
      
      
        
    • document.querySelector(".card") returns the first match, or null if nothing matches.
      • 
        
    • document.querySelectorAll(".card") returns every match as a NodeList. Loop over it with for...of.
      • 
        
    • Change text with el.textContent = "…".
      • 
        
    • Prefer el.classList.add(), .remove() and .toggle() with styles in your CSS file over setting el.style directly. It keeps CSS and JS separate.
      • 
        
    • In el.style, CSS property names become camelCase: background-color → backgroundColor.
      • 
        
    • Family words: a parent directly contains its children; siblings share a parent; descendants are anything inside, at any depth.
      • 
      
    
    
    
    
    
      
    Common mistakes
    
      
      
        
    • Forgetting the . or #: querySelector("card") looks for a <card> element and returns null.
      • 
        
    • Adding a # with getElementById: getElementById("#title") returns null. It takes the plain id.
      • 
        
    • Treating a NodeList like one element: cards.classList.add() fails. Loop over the list.
      • 
        
    • Selecting elements before they exist, because the script isn't deferred.
