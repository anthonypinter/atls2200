Picture & Lazy Loading

Three more ways to send the right image: tell the browser how wide it will be with sizes, swap in a different crop with <picture>, and skip images nobody scrolls to with loading="lazy".

You'll be able to

  • Tell the browser how wide an image will be with the sizes attribute.
  • Show a different crop on small screens with picture and source.
  • Lazy-load images further down the page, but never the first one.
Read

Send the right image, at the right time

With srcset, the browser picks a file based on how wide the image will be. But the browser chooses which file to download before your CSS has loaded, so it doesn't know your layout. Unless you say otherwise, it assumes the image fills the whole window. The sizes attribute tells it:

<img srcset="mesa-400.jpg 400w, mesa-800.jpg 800w, mesa-1600.jpg 1600w"
     sizes="(min-width: 900px) 33vw, 100vw"
     src="mesa-800.jpg" alt="Mesa Trail at sunrise">

Read it as: "on screens 900px and wider, this image is a third of the window wide; otherwise it's the full width." Now a small card image on a laptop downloads a small file.

Sometimes a smaller copy isn't enough. A wide landscape shrunk onto a phone turns the arch into a speck. Showing a tighter crop on small screens is called art direction, and picture does it:

<picture>
  <source media="(max-width: 600px)" srcset="arch-tall.jpg">
  <img src="arch-wide.jpg" alt="Royal Arch above the trees">
</picture>

The browser uses the first <source> that matches, or falls back to the <img>. The <img> is required: it's what actually shows the picture.

Finally, loading="lazy" waits to download an image until the visitor scrolls near it. On a long page, that saves data for everyone who never scrolls to the bottom. This is called lazy loading.

Watch out

Don't lazy-load the big image at the top of the page. It's the first thing visitors see, so it should start downloading as early as possible.

Key ideas

      
    
        
  • Use srcset with w widths (trail-800.jpg 800w) plus sizes when the image isn't full-width. Use 1x/2x only for images with a fixed size, like a logo.
    • 
        
  • sizes describes your layout. If your CSS changes the columns, update sizes to match.
    • 
        
  • <picture> with media changes the crop. With type it offers a newer format and falls back: <source type="image/avif" srcset="arch.avif">.
    • 
        
  • Put loading="lazy" on images and iframes further down the page, and keep width and height so the page doesn't jump when they arrive.
    • 
      

    

    

      
Common mistakes

      
    
        
  • Leaving out sizes with w descriptors, so a small card image downloads at full-window size.
    • 
        
  • Using <picture> only to switch sizes. srcset and sizes on a plain <img> already do that, and let the browser choose.
    • 
        
  • Forgetting the <img> inside <picture>. Without it, nothing shows.
    • 
        
  • Lazy-loading the big photo at the top of the page. It should load as early as possible.
