Picture & Lazy Loading

Three more ways to send the right image: tell the browser how wide it will be with sizes, swap in a different crop with <picture>, and skip images nobody scrolls to with loading="lazy".

Part 1

Tell the browser the size with sizes

The browser picks a file from srcset before your CSS has loaded, so it doesn't know how wide the image will be. Without sizes, it assumes the full window width. This layout shows 1, 2 or 3 cards per row.

Read sizes left to right: the first media condition that's true wins, and the last value has no condition, so it's the default.


    

  


  
Part 2
Change the crop with <picture>
Sometimes a smaller copy isn't enough. A wide landscape shrunk onto a phone makes the arch a speck. <picture> lets you send a different crop at different widths. This is called art direction.

  

    

      

      
The browser checks each <source> in order and uses the first one whose media matches. If none match, it uses the <img>.

      
The <img> is required. It holds the alt text, and any CSS you write targets the img, not the picture.

    

    

      

      

    

  


  
Part 3
Skip what nobody sees with loading="lazy"
Scroll the page on the left and watch the network log. With lazy loading, images download just before they scroll into view.

  

    

      

      
The first image is above the fold, so it is always loaded right away. Lazy-loading it would only make the page feel slower.

Key ideas

      
    
        
  • Use srcset with w widths (trail-800.jpg 800w) plus sizes when the image isn't full-width. Use 1x/2x only for images with a fixed size, like a logo.
    • 
        
  • sizes describes your layout. If your CSS changes the columns, update sizes to match.
    • 
        
  • <picture> with media changes the crop. With type it offers a newer format and falls back: <source type="image/avif" srcset="arch.avif">.
    • 
        
  • Put loading="lazy" on images and iframes further down the page, and keep width and height so the page doesn't jump when they arrive.
    • 
      

    

    

      
Common mistakes

      
    
        
  • Leaving out sizes with w descriptors, so a small card image downloads at full-window size.
    • 
        
  • Using <picture> only to switch sizes. srcset and sizes on a plain <img> already do that, and let the browser choose.
    • 
        
  • Forgetting the <img> inside <picture>. Without it, nothing shows.
    • 
        
  • Lazy-loading the big photo at the top of the page. It should load as early as possible.
