DOM Scripting

When the browser reads your HTML, it builds a tree of objects in memory. JavaScript can find any element in that tree and change its text, its attributes, its classes and its styles, and the page updates immediately.

You'll be able to

  • Name the main parts of the browser JavaScript can reach: window, navigator and document.
  • Read the DOM as a tree of parents, children and siblings.
  • Find elements with querySelector() and querySelectorAll(), and change their text and attributes.
  • Create, move and remove elements, and change styles with classList and style.

The important parts of a web browser

JavaScript in a web page can reach several objects the browser provides:

  • window is the browser tab the page is loaded into. It knows things like the window's size (window.innerWidth) and can run code when it's resized.
  • navigator represents the browser itself: its preferred language, the user's location (with permission), and more.
  • document is the page loaded into the window. It's your way into the DOM, the Document Object Model, and the object you'll use most.

The document object model

The DOM is a tree of objects, one for each element (and each piece of text) in the page. JavaScript can't change your HTML file, but it can change the DOM, and the page updates immediately.

The DOM uses the same family words as CSS. Each object in the tree is a node. The top one, <html>, is the root. A parent node directly contains its children; children of the same parent are siblings; and anything inside a node, at any depth, is a descendant.

Basic DOM manipulation

To change an element, first find it and store a reference to it in a variable. querySelector() takes any CSS selector and returns the first match:

const link = document.querySelector("a");
link.textContent = "Mozilla Developer Network";
link.href = "https://developer.mozilla.org";

textContent reads or replaces an element's text, and attributes like href and src are properties you can set directly.

querySelectorAll() returns every match as a list you can loop over. Older code uses getElementById() and getElementsByTagName(); they still work, but querySelector() handles any selector.

Watch out

If nothing matches, querySelector() returns null, and using it gives the error "Cannot read properties of null." That almost always means a typo in your selector, or a script that ran before the element existed.

    Moving and removing elements
    
  
    

    Appending an element that's already in the page moves it rather than copying it. To make a copy, use cloneNode(). To take an element out, call its remove() method (older code calls parent.removeChild(child)).

    Manipulating styles
    
  
    

    There are two ways to change how an element looks. The first sets inline styles through the style property. CSS properties with hyphens become camelCase, because hyphens aren't allowed in JavaScript names:
    
    
    para.style.color = "white";
para.style.backgroundColor = "black";
para.style.padding = "10px";
    
    
    The second, usually better, adds a class and keeps the styles in your CSS file, where they belong. classList has add(), remove() and toggle():
    
    
    para.classList.add("highlight");
    
    
    Tip
    Write the selector in your CSS file first and make sure it styles the right element. Then use the same selector in JavaScript.

    Key ideas
    
      
      
        
    • window is the tab, navigator the browser, and document the page and its DOM.
      • 
        
    • querySelector() returns the first match, or null; querySelectorAll() returns every match.
      • 
        
    • Change text with textContent and attributes like href directly.
      • 
        
    • createElement() makes an element; appendChild() places it (or moves it); remove() takes it out.
      • 
        
    • Prefer classList over style, so styles stay in CSS.
      • 
      
    
    
    
    
    
      
    Common mistakes
    
      
      
        
    • A script that runs before the elements exist, so querySelector() returns null. Use defer.
      • 
        
    • Treating the list from querySelectorAll() as one element: cards.classList is undefined. Loop over it.
      • 
        
    • Writing el.style.background-color. Use camelCase: backgroundColor.
      • 
        
    • Using innerHTML with text people typed. Use textContent.
