Key ideas

      
    
        
  • Parameters are the names in the definition: function hikeTime(miles, pace). Arguments are the values you pass in when you call it: hikeTime(6.7, 2.5).
    • 
        
  • Calling a function needs parentheses. Without them, you're just referring to the function, not running it.
    • 
        
  • return sends a value back to wherever the function was called, and ends the function right there.
    • 
        
  • Default parameters fill in missing arguments: function greet(name = "friend").
    • 
        
  • Functions inside objects are called methods, like text.toUpperCase() or console.log().
    • 
      

    

    

      
Common mistakes

      
    
        
  • Using console.log() where you meant return. The value is printed, but the caller gets undefined.
    • 
        
  • Passing a function call instead of the function: btn.addEventListener("click", go()) runs go right away. Use go with no parentheses.
    • 
        
  • Using a variable declared inside a function from outside it: ReferenceError.
    • 
        
  • Putting code after return and expecting it to run.
    •
