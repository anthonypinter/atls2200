Taking an element out of the flow

Normally every element sits where the normal flow puts it, one after another. The position property lets you move an element from there. The question each value answers is: measured from where?

  • static is the default. top and left do nothing.
  • relative nudges the element from where it would have been. Its original space stays reserved, so nothing else moves.
  • absolute takes the element out of the flow completely and places it inside its nearest positioned ancestor.
  • fixed places it relative to the browser window, so it stays put while you scroll.
  • sticky scrolls normally until it reaches its top value, then sticks there until its parent scrolls away.

The pattern you'll use most combines two of them. To pin a "New" badge to the corner of a card, make the card the reference point with position: relative, then place the badge with absolute:

.card { position: relative; }
.card .badge {
  position: absolute;
  top: 8px;
  right: 8px;
}

Without position: relative on the card, the badge looks for the next positioned ancestor up the page and often ends up in the corner of the whole page.

When positioned elements overlap, z-index decides which is on top: higher numbers come forward. It only works on positioned elements (and flex and grid items).

Watch out

Don't build whole layouts with absolute positioning. Absolutely placed boxes don't make room for each other, so they overlap as soon as the text or screen size changes. Use Flexbox or Grid for layout, and positioning for overlays, badges and sticky headers.

Key ideas

  • static is the default. top and left do nothing.
  • relative nudges the element from where it would have been. Its original space stays reserved.
  • absolute removes the element from the flow and places it inside the nearest positioned ancestor. That's why you put position: relative on the parent.
  • fixed places it relative to the browser window, so it stays put while you scroll.
  • sticky scrolls normally until it reaches the top value, then sticks until its parent scrolls away.

Common mistakes

  • Using absolute without a positioned parent, so the element flies to the corner of the page.
  • Building whole layouts with absolute positioning. Use Flexbox or Grid, and save positioning for overlays and badges.
  • Setting z-index on a static element. It only works on positioned (or flex and grid) items.
  • Sticky that never sticks because a parent has overflow: hidden, or no top value is set.
