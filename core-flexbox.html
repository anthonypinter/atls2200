Flexbox

Flexbox lays out items in one direction, a row or a column. You set the rules on the container and its children follow them, sharing out space, lining up and wrapping as the room changes.

You'll be able to

  • Turn a parent into a flex container and name its main and cross axes.
  • Change direction and wrapping with flex-direction, flex-wrap and flex-flow.
  • Share out space between items with the flex shorthand.
  • Align items with justify-content, align-items and align-self, and reorder them with order.
Read

Why flexbox?

For a long time, CSS had no good way to do some very common things: center a box vertically inside its parent, make several columns share the available width equally, or make columns the same height whatever their content. People used floats and workarounds that broke easily.

Flexbox was designed for exactly these jobs. It lays items out along one line, a row or a column, and gives you control over how they share space and line up.

Specifying what elements to lay out as flexible boxes

Add display: flex to a parent, and its direct children line up in a row:

section {
  display: flex;
}

The parent becomes the flex container, and its children become flex items. Only direct children: grandchildren are laid out normally unless their own parent is also a flex container. Almost every rule goes on the container, which is also the most common mistake. display: flex goes on the parent, not on the items you want to move.

The flex model

Every flex container has two directions:

  • The main axis runs the way items flow. With the default flex-direction: row, that's left to right. Its two ends are the main start and main end, and an item's length along it is its main size.
  • The cross axis runs at a right angle to it, so up and down in a row, from cross start to cross end. An item's length along it is its cross size.

Most flex properties work along one axis or the other, so keep track of which way the main axis runs.

Read

Columns or rows?

flex-direction sets the main axis: row (the default), column, or row-reverse and column-reverse, which run backwards. Switch to column and the axes swap: the main axis now runs top to bottom.

Read

Wrapping

Flex items don't wrap by default. When they run out of room they shrink, and if they can't shrink any more, they overflow the container. flex-wrap: wrap lets them move onto a new line instead. Each new line is laid out on its own.

Read

flex-flow shorthand

flex-flow sets both at once, direction first:

.cards { display: flex; flex-flow: row wrap; }

Flexible sizing of flex items

Now for the items themselves. The flex property on an item says how much of the container's spare space it should take:

article { flex: 1; }               /* every article gets an equal share */
article:nth-child(3) { flex: 2; }   /* this one gets two shares */

The number has no unit: it's a proportion. With flex: 1, flex: 1 and flex: 2, the space is split into four shares, and the third item gets two of them.

You can add a starting size too. flex: 1 200px means "start at 200px, then share out whatever space is left". That's useful for items that shouldn't get too narrow.

flex: shorthand versus longhand

flex is a shorthand for three properties:

  • flex-grow: how many shares of spare space the item takes (the unitless number).
  • flex-shrink: how much it shrinks, compared with the others, when there isn't enough room.
  • flex-basis: its starting size before space is shared out.

Use the shorthand: it sets sensible values for the parts you leave out. flex: 1 is 1 1 0% (grow, shrink, start from nothing), while the initial value is 0 1 auto (don't grow, but do shrink, and start from the content's size). flex: none is 0 0 auto: a fixed size that neither grows nor shrinks.

Horizontal and vertical alignment

You've already met the two container properties in the playground above:

  • align-items lines items up on the cross axis. The default, stretch (its keyword is normal), makes every item as tall as the tallest, which is how flexbox gives you equal-height columns. flex-start, center, flex-end and baseline keep each item's own height.
  • justify-content spaces items along the main axis: flex-start, center, flex-end, space-between (no space at the ends), space-around (half-size space at the ends) and space-evenly.

To align just one item differently, put align-self on it. It takes the same values as align-items. (There's no justify-self in flexbox: a single item's main-axis position comes from the free space, so use margin-left: auto to push one item to the end.)

.row { display: flex; align-items: center; }
.row .tall { align-self: stretch; }

Ordering flex items

The order property changes where an item appears without changing the HTML. Every item starts at order: 0. Items with lower values come first; items with the same value keep their source order. Negative numbers work too, so order: -1 moves an item to the front.

Use it sparingly. order only changes what people see: keyboard users still tab through the items in source order, and screen readers still read them in source order. If the order matters, change the HTML.

Nested flex boxes

  


A flex item can be a flex container too. That's how most real layouts are built: a header is a flex row (logo on one side, nav on the other), and the nav inside it is another flex row of links.

    
.site-nav { display: flex; justify-content: space-between; align-items: center; }
.site-nav ul { display: flex; gap: 16px; }

    
Each container only lays out its own direct children, so you can mix rows, columns and wrapping at every level.

    
Note
Flexbox handles one direction at a time. For rows and columns that line up together, use Grid. Flexbox or Grid? builds the same layouts both ways.

Key ideas

      
    
        
  • display: flex goes on the parent; its direct children become flex items.
    • 
        
  • justify-content works along the main axis, set by flex-direction; align-items works along the cross axis.
    • 
        
  • Items don't wrap unless you add flex-wrap: wrap. flex-flow sets direction and wrap together.
    • 
        
  • flex: 1 shares out spare space; flex: 1 200px starts at 200px first. flex is shorthand for grow, shrink and basis.
    • 
        
  • align-self aligns one item; order moves it visually but not for the keyboard.
    • 
      

    

    

      
Common mistakes

      
    
        
  • Putting display: flex on the items instead of their parent.
    • 
        
  • Expecting align-items: center to center vertically when the container has no extra height.
    • 
        
  • Forgetting flex-wrap: wrap, so items squish instead of moving to a new line.
    • 
        
  • Using order to fix content that's in the wrong order in the HTML.
