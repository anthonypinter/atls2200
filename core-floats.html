Floats

A floated element moves to the left or right, and the text flows around it, like a photo in a magazine. That's still the job floats do best. Before Flexbox and Grid existed they were also used for whole-page layouts, so you'll see them in older code.

You'll be able to

  • Wrap text around an image with float and a margin.
  • Explain why margin on the text doesn't move it away from a float.
  • Start an element below floats with clear.
  • Fix a parent that doesn't contain its floats with display: flow-root.

Optional lesson

You won't need floats for new layouts: Flexbox and Grid do that job better. This lesson is here so you can wrap text around images, and so you can read older CSS.

The background of floats

The float property was added to CSS for one job: letting an image sit to one side of a column of text, with the text wrapping around it, the way magazines and newspapers have always done it. It's also used for drop caps, a large first letter that the paragraph wraps around.

Before Flexbox and Grid, floats were the only way to put boxes side by side, so developers built entire multi-column page layouts out of them, along with workarounds like the "clearfix" hack. That's a legacy technique now, but there's a lot of it in older code and tutorials.

A float example

Floating the box

float: left takes the element out of the normal flow and moves it to the left edge of its container. The content that follows wraps around its right side. float: right does the mirror image.

.box {
  float: left;
  width: 150px;
  margin-right: 15px;   /* space between the box and the text */
}

Give a floated element a width, or it shrinks to fit its content. And put a margin on the side facing the text, so the words don't press right against it.

Visualizing the float

Here's something surprising. The paragraphs beside a float aren't actually narrower: their boxes still run the full width, right behind the float. Only the lines of text inside them are shortened to make room.

That's why a margin on the float pushes the text away, but a margin on the paragraph doesn't seem to do anything: the paragraph's left edge is already behind the float, so a small margin-left just moves its hidden edge further behind it.

Clearing floats

Everything after a float wraps around it, until you tell an element not to. The clear property moves an element down until it's below the floats:

  • clear: left clears floats on the left.
  • clear: right clears floats on the right.
  • clear: both clears any floats.

Use it on whatever should start fresh, like the next section's heading. You tried clear: both in the first playground: turn it on there again and watch "Getting there" drop below the photo.

Clearing boxes wrapped around a float

The problem

A floated element doesn't count toward its parent's height. If a box contains a float that's taller than the rest of its content, the box ends before the float does: its background and border stop short, the float hangs out of the bottom, and the next element tries to wrap around it.

display: flow-root

The modern fix is one line on the parent:

.wrapper {
  display: flow-root;
}

flow-root makes the box a new block formatting context: a self-contained area whose floats stay inside it. Older code used the "clearfix" hack (an ::after pseudo-element with clear: both) to do the same thing.

Key ideas

  • Floats are for wrapping text around images. For layout, use Flexbox or Grid.
  • A floated element needs a width, and a margin on the side facing the text.
  • Text beside a float is shortened, but its box runs behind the float, so margin on the text doesn't push it away.
  • clear: left, right or both makes an element start below the floats.
  • display: flow-root on the parent makes it contain its floats.

Common mistakes

  • Building columns with floats, then fighting collapsed parents and uneven heights.
  • Trying to space text from a float with a margin on the paragraph instead of the float.
  • Forgetting that floats don't work on flex or grid items. The float is ignored.
  • On phones, a floated image squeezes the text into a narrow strip. Remove the float on small screens.
