Writing colors and sizes

CSS gives you several ways to write the same color. These all mean the same teal:

color: #0b6b5e;              /* hex */
color: rgb(11 107 94);       /* red, green, blue: 0 to 255 */
color: hsl(172 81% 23%);     /* hue, saturation, lightness */
color: rgb(11 107 94 / 50%); /* the same teal, half transparent */

A hex color is three pairs of digits for red, green and blue, from 00 to ff. Designers hand you hex codes, so you'll see them often. HSL is the easiest to adjust by hand: the hue is a spot on the color wheel from 0 to 360, saturation runs from gray to vivid, and lightness from black to white. To make a lighter version of a color, raise the lightness.

Sizes need a unit, and each unit is measured from something different:

  • px is a fixed size.
  • rem is a multiple of the root font size, usually 16px.
  • em is a multiple of the parent's font size.
  • % is a share of the parent, usually its width.
  • vw and vh are a percentage of the window's width and height.

Use rem for font sizes. Some people set a larger default text size in their browser so they can read comfortably. Sizes in rem grow with that setting; sizes in px ignore it. Use % or max-width for widths, so layouts can shrink on phones.

Watch out

Light gray text on white looks sleek, and many people can't read it. Check the contrast ratio of your text and background. DevTools shows it when you inspect a color.

Pick better units

These pixel values ignore the reader's settings and the screen size. Swap in units that adapt.

Key ideas

  • Hex like #2340d9 is pairs of red, green and blue, from 00 to ff.
  • Add transparency with a fourth value: rgb(35 64 217 / 50%).
  • Use rem for font sizes so text grows when someone sets a larger default size in their browser.
  • Use %, fr or max-width for widths so layouts can shrink on phones.
  • em depends on the parent, so nested em sizes multiply. That's why most people prefer rem.

Common mistakes

  • Light gray text on white. It looks sleek and fails contrast, so many people can't read it.
  • Forgetting the # on a hex color, or the unit on a size: width: 200 does nothing.
  • Setting width: 100vw, which ignores the scrollbar and causes sideways scrolling.
  • Using px for everything, so the page ignores the user's font size setting.
