Flexbox Playground

Flexbox lays out items in one direction, a row or a column. You set the rules on the container, and its direct children (the flex items) follow them.

Key ideas

  • justify-content works along the main axis, which is the direction set by flex-direction.
  • align-items works along the cross axis, perpendicular to the main axis.
  • Switch to column and the two swap: now justify-content moves things up and down.
  • gap adds space between items without margins on each one.

Common mistakes

  • Putting display: flex on the items instead of their parent.
  • Expecting align-items: center to center vertically when the container has no extra height.
  • Forgetting flex-wrap: wrap, so items squish instead of moving to a new line.
  • Using Flexbox for a full two-dimensional grid. Reach for CSS Grid instead.
