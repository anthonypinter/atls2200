Layout · Flexbox

Flexbox Playground

Flexbox lays out items in one direction, a row or a column. You set the rules on the container, and its direct children (the flex items) follow them.

You'll be able to

  • Turn a parent into a flex container and line its children up in a row or a column.
  • Tell the main axis from the cross axis, and choose justify-content or align-items to match.
  • Space items with gap and let them wrap onto new lines.
Read

One direction at a time

Putting boxes side by side used to take floats and workarounds. Flexbox does it in one line: add display: flex to a parent, and its direct children line up in a row.

The parent becomes the flex container, and its children become flex items. Almost every rule goes on the container. That's also the most common mistake: display: flex goes on the parent, not on the items you want to move.

Every flex container has two directions:

  • The main axis runs the way items flow. With the default flex-direction: row, that's left to right. justify-content spaces items along it.
  • The cross axis runs at a right angle to it, so up and down in a row. align-items lines items up along it.

Switch to flex-direction: column and the axes swap. Now justify-content moves items up and down, and align-items moves them side to side. If a property seems to do the wrong thing, check which way your main axis runs.

.site-nav {
  display: flex;
  justify-content: space-between;  /* main axis: spread out */
  align-items: center;            /* cross axis: center vertically */
  gap: 16px;                      /* space between items */
}

Use gap for space between items instead of margins on each one. And remember that items don't wrap by default: when they run out of room, they shrink. Add flex-wrap: wrap to let them move onto a new line instead.

Note

Flexbox handles one direction at a time. For rows and columns together, like a photo gallery, use CSS Grid. Flexbox vs Grid builds the same layouts both ways.

Key ideas

  • justify-content works along the main axis, which is the direction set by flex-direction.
  • align-items works along the cross axis, perpendicular to the main axis.
  • Switch to column and the two swap: now justify-content moves things up and down.
  • gap adds space between items without margins on each one.

Common mistakes

  • Putting display: flex on the items instead of their parent.
  • Expecting align-items: center to center vertically when the container has no extra height.
  • Forgetting flex-wrap: wrap, so items squish instead of moving to a new line.
  • Using Flexbox for a full two-dimensional grid. Reach for CSS Grid instead.
