Values and Units

Every declaration ends in a value: a colour, a length, a percentage, an image, a function. Knowing the kinds of value CSS accepts, and what each unit is measured against, is what makes a layout adapt instead of break.

You'll be able to

  • Read value types like <length> and <color> on MDN reference pages.
  • Choose between absolute and relative units, and explain how em and rem differ.
  • Write colours as keywords, hex, rgb() and hsl(), with transparency.
  • Use images, positions, strings and math functions like calc() and clamp() as values.

What is a CSS value?

On MDN's reference pages, the kinds of value a property accepts are written in angle brackets: <color>, <length>, <percentage>. These are value types, not HTML elements. So when the page for color says it accepts a <color>, any of the colour formats below will work:

h1 {
  color: black;                      /* a keyword */
  background-color: rgb(197 93 161); /* a function */
}

Numbers, lengths, and percentages

Lengths

A length is a number with a unit, with no space between them. There are two families:

  • Absolute units are always the same size: px (pixels) is the one you'll use. Print units like cm, in and pt exist, but don't belong on screens.
  • Relative units are measured from something else, so they adapt:
    • em: the font size of the element itself (for font-size, the parent's).
    • rem: the font size of the root element, <html>, usually 16px.
    • vw and vh: 1% of the browser window's width and height.

ems and rems

em sizes compound. In a nested list where each li is 1.3em, every level is 1.3 times its parent, so text grows as you go deeper. rem always measures from the root, so every level is the same size.

Percentages

A percentage is always a share of something else, usually the parent's size. width: 40% is 40% of the parent's width; font-size: 80% is 80% of the parent's font size.

Numbers

Some properties take a plain number with no unit: opacity: 0.6 (0 is invisible, 1 solid) or line-height: 1.5 (1.5 times the font size).

Which unit?

Use rem for font sizes: people who set a larger default text size in their browser get bigger text, while px ignores that setting. Use % or max-width for widths so boxes fit small screens. Keep px for things that should stay fixed, like borders.

Color

Color keywords

CSS has around 150 named colours, like teal, antiquewhite and rebeccapurple. Handy for quick tests, but you can't fine-tune them.

Hexadecimal RGB values

A hex color like #02798b is three pairs of hexadecimal digits for red, green and blue, each from 00 to ff. Designers hand you hex codes, so you'll see them everywhere.

RGB values

rgb(2 121 139) is the same idea in decimal: red, green and blue from 0 to 255. Add a slash and a fourth value for transparency (the alpha channel): rgb(2 121 139 / 30%) is 30% opaque.

Using hues to specify a color

Mixing red, green and blue in your head is hard. Hue-based formats start from a position on the colour wheel, in degrees: 0 is red, 120 green, 240 blue.

  • HSL: hsl(188 97% 28%) is hue, saturation (grey to vivid) and lightness (black to white). Keep the hue and change the lightness for a matching darker or lighter shade. Transparency works the same way: hsl(188 97% 28% / 30%).
  • HWB: hwb(188 0% 45%) is hue, then how much white and black to mix in.

Images, position, and strings

Images

An <image> value can be a file, with url(), or a gradient that CSS draws for you:

background-image: url("images/arch.jpg");
background-image: linear-gradient(90deg, rgb(119 0 255 / 39%), rgb(0 212 255 / 25%));

Position

A <position> places something, like a background image, in a box. It takes keywords (top, right, center…), lengths, or both: background-position: right 60px means against the right edge, 60px from the top.

Strings and identifiers

Keywords like red or center are identifiers: written without quotes. Some places need a string of text in quotes, like generated content: content: "New!";.

Functions

  


A function is a name followed by brackets, which CSS works out for you. You've already met rgb(), hsl(), url() and gradients.

    
Math functions

    
    
      
  • calc() mixes units: width: calc(20% + 100px).

  • min() picks the smallest of its values, max() the largest: width: min(100%, 600px) is never wider than 600px or its parent.
    • 
      
  • clamp() takes a minimum, a preferred value and a maximum: font-size: clamp(1rem, 4vw, 2rem).

Key ideas

      
    
        
  • Value types like <length> and <color> tell you what a property accepts.
    • 
        
  • px is fixed; em, rem, %, vw and vh adapt.
    • 
        
  • em compounds through nested elements; rem always measures from the root.
    • 
        
  • Hex, rgb() and hsl() can all describe the same colour; add / 50% for transparency.
    • 
        
  • calc(), min(), max() and clamp() do the math for you.
    • 
      

    

    

      
Common mistakes

      
    
        
  • A space between number and unit (16 px), or no unit at all on a length.
    • 
        
  • Font sizes in px, which ignore the reader's text-size setting.
    • 
        
  • Nested em font sizes that grow (or shrink) out of control.
    • 
        
  • Low-contrast text, like light grey on white.
    • 
        
  • calc(20%+100px) without spaces around the +: it's invalid.
