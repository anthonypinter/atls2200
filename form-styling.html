Forms that feel like part of the page

Browsers style form controls their own way, and a little differently in each browser. The results look cramped and out of place. A handful of rules fixes most of it.

Start with fonts. Inputs, selects, text areas and buttons don't inherit the page's font the way other elements do, so they show up smaller, in the browser's default face. One line brings them in line:

input, select, textarea, button {
  font: inherit;
}

Next, layout. Put each label above its input and make the input full width. That's the easiest arrangement to scan, and it works on a phone without any media queries. Add padding so the text isn't pressed against the edge, and set box-sizing: border-box so width: 100% plus padding doesn't poke out of the container.

accent-color recolors checkboxes, radio buttons and range sliders to match your site in one line.

Then the states. Visitors need to see which field they're in, so give :focus-visible a clear outline rather than removing it. For errors, :user-invalid matches a field that breaks its rules, such as a required field left empty, but only after the visitor has interacted with it. Unlike :invalid, it won't paint the whole form red before anyone has typed a thing.

Watch out

Don't show errors with color alone. Some visitors can't tell red from green. Add a text message next to the field explaining what's wrong.

Key ideas

  • Inputs, selects and buttons don't inherit fonts. Start every form with font: inherit.
  • Put labels above inputs. It's easiest to scan and works on narrow screens.
  • accent-color recolors checkboxes, radios and range sliders in one line.
  • :user-invalid only shows errors after someone has interacted with a field, not as soon as the page loads.

Common mistakes

  • Removing the focus outline and replacing it with nothing.
  • width: 100% plus padding without box-sizing: border-box, so inputs poke out of their container.
  • Showing errors in red only. Add a text message too, for people who can't tell the colors apart.
  • Tiny checkboxes and buttons that are hard to tap on a phone.
