Backgrounds and Borders

Backgrounds fill a box with colour, images or gradients, stacked in as many layers as you like. Borders frame it, and rounded corners soften it. Together they're most of what makes a plain box look designed.

You'll be able to

  • Set background colours and images, and control their repeat, size and position.
  • Draw linear and radial gradients, and stack several background layers.
  • Use background-attachment and the background shorthand.
  • Style borders on one side or all four, and round the corners.
Read

Background colors

background-color fills the content and padding of a box (the area inside the border). It works on any element, including inline ones like a <span>. A semi-transparent colour, like rgb(255 255 255 / 50%), lets whatever's behind show through.

Read

Background images

background-image: url("star.png") puts an image behind the content. By default, it's shown at its natural size and tiled to fill the box. A background colour shows through wherever the image is transparent or doesn't reach.

Controlling background-repeat

no-repeat, repeat-x (tile across), repeat-y (tile down), repeat (the default), plus space and round, which fit a whole number of tiles.

Sizing the background image

background-size takes lengths or percentages (80px 10em), or a keyword: cover fills the whole box, cropping the image if needed; contain fits the whole image inside, leaving gaps.

Positioning the background image

background-position takes keywords (top center), lengths and percentages (20px 10%), or edge offsets: top 20px right 10px is 20px from the top and 10px from the right.

Watch out

An empty element has no height, so its background is invisible. Backgrounds fill the box; give the box some content, padding or a height.

Gradient backgrounds

A gradient is an image that CSS draws, so it goes in background-image, not background-color:

.a { background-image: linear-gradient(105deg, rgb(0 249 255) 39%, rgb(51 56 57) 96%); }
.b { background-image: radial-gradient(circle, rgb(0 249 255) 39%, rgb(51 56 57) 96%); }

A linear gradient runs along an angle; a radial one spreads out from a point. Each colour can have a stop position, a percentage along the way.

Read

Multiple background images

background-image takes a comma-separated list. The first layer is drawn on top. The other background properties take lists too, matched up in the same order:

.hero {
  background-image: url("star.svg"), linear-gradient(135deg, #0b6b5e, #2340d9);
  background-repeat: no-repeat, no-repeat;
  background-position: right 12px top 12px, center;
}

A classic use: a dark gradient over a photo, so white text on top stays readable.

    Background attachment
    
  
    

    background-attachment decides what the background scrolls with:
    
    
      
      
    • scroll (default): fixed to the element; when the page scrolls, it moves with the element, but if the element itself scrolls, the background stays put.
      • 
      
    • fixed: fixed to the window, so content slides over it. Used for "parallax" effects.
      • 
      
    • local: fixed to the element's content, so it scrolls along with the text inside.
      •

    Using the background shorthand property
    
  
    

    background sets everything at once, with layers separated by commas. Two rules: the colour can only go in the last layer, and a size must come straight after the position, with a slash: center / 80%.
    
    
    .box {
  background:
    url("star.svg") no-repeat right 10px top 10px / 40px,
    linear-gradient(105deg, rgb(255 255 255 / 20%) 39%, rgb(51 56 57 / 100%) 96%) center / 400px 200px no-repeat,
    rebeccapurple;
}

    Accessibility considerations with backgrounds
    
  
    

    Text on top of a background image must still have enough contrast, everywhere the text might land, at every screen size. Set a background colour too, so text stays readable if the image doesn't load. And background images are for decoration: screen readers ignore them, so anything that carries meaning belongs in an <img> with alt text.

    Borders
    
  
    

    A border needs a width, a style and a colour: border: 1px solid black. Leave out the style and nothing appears, because the default is none. Every part has longhands: one side (border-top), one quality (border-width), or both (border-bottom-style):
    
    
    .box {
  border: 1px solid black;
  border-bottom: 1em double rgb(24 163 78);
}
    
    
    Styles include solid, dashed, dotted, double, groove and ridge.

    Rounded corners
    
  
    

    border-radius: 10px rounds all four corners, even without a border. Each corner has a longhand, like border-top-right-radius, and two values make an elliptical corner: border-top-right-radius: 1em 10%. border-radius: 50% turns a square into a circle.

    Key ideas
    
      
      
        
    • background-color fills inside the border; images and gradients go in background-image.
      • 
        
    • background-size: cover fills and crops; contain fits the whole image.
      • 
        
    • Multiple backgrounds are comma-separated; the first is on top.
      • 
        
    • In the background shorthand, the colour goes last and size follows position after a slash.
      • 
        
    • Borders need a style; border-radius rounds corners, 50% makes a circle.
      • 
      
    
    
    
    
    
      
    Common mistakes
    
      
      
        
    • A gradient in background-color, where it's ignored.
      • 
        
    • A background on an empty element with no height.
      • 
        
    • Text over a photo with no overlay or fallback colour, so it's unreadable.
      • 
        
    • border: 2px navy with no style.
      • 
        
    • Putting meaningful images in CSS backgrounds, where screen readers can't see them.
