Cascade & Inheritance

Some styles pass down from parent to child automatically, and some don't. When several rules disagree, the cascade decides which one wins.

Passing styles down, and settling arguments

Two systems decide the final style of every element. Inheritance passes styles down from parent to child. The cascade settles arguments when several rules disagree.

Inheritance is why you can set a font once and have the whole page use it:

body {
  font-family: "Atkinson Hyperlegible", sans-serif;
  color: #161a2b;
  line-height: 1.6;
}

Every element inside body inherits those, because text properties inherit: color, font-*, line-height, text-align. Box properties don't. A border on a <section> doesn't put a border on every paragraph inside it, and neither do padding, margin, background or width. If a child looks like it inherited a background, it's actually transparent, and you're seeing the parent behind it.

When rules disagree about the same property on the same element, the cascade checks, in order:

  1. Importance: a declaration marked !important beats normal ones.
  2. Specificity: IDs beat classes, classes beat element types.
  3. Source order: if everything else ties, the rule that comes later wins.

That last rule includes the order of your <link> tags. Link a general stylesheet after a specific one, and the general one can win.

Tip

Buttons and inputs don't inherit your font and color. Add button, input, select, textarea { font: inherit; color: inherit; } near the top of your stylesheet, and forms match the rest of the page.

Let it inherit

This stylesheet sets the same font and color three times. Set them once and let inheritance do the rest.

Key ideas

  • Text properties inherit: color, font-*, line-height, text-align.
  • Box properties don't: border, padding, margin, background, width.
  • Set your fonts and text color once on body and let everything inherit them.
  • Any property can be forced to inherit with the value inherit.

Common mistakes

  • Wondering why buttons and inputs ignore your font and color. They don't inherit them unless you add font: inherit and color: inherit.
  • Thinking a background was inherited. Children are transparent, so you're seeing the parent through them.
  • Fixing a losing rule with !important instead of checking order and specificity in DevTools.
  • Linking two stylesheets in the wrong order, so the general one overrides the specific one.
