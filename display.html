Display Types

Every element is either block (starts on a new line, fills the width) or inline (flows inside text like a word). That's why width works on a div and does nothing on a span.

Block or inline?

In normal flow, before you add any layout, every element is one of two kinds:

  • A block element starts on a new line and stretches to fill the width of its parent. div, p, h1–h6, ul and section are blocks.
  • An inline element flows inside a line of text, like a word. span, a, strong and em are inline.

The difference explains a classic puzzle: why width works on a div but does nothing on a link. Inline elements take their size from their content, so they ignore width, height and top and bottom margins.

The display property changes how an element behaves:

.badge {
  display: inline-block;   /* flows like a word, but accepts a size */
  padding: 4px 10px;
  width: 80px;
}

inline-block is the middle ground: it sits in a line of text like a word, but takes width, height and margins like a block. It's handy for buttons and badges. display: flex and grid are different again: they change how an element's children are laid out, which you'll meet in the Layout part.

display: none removes an element completely, and the space it took up closes. visibility: hidden and opacity: 0 hide it but keep its space.

Note

Changing display changes how an element looks, never what it means. A span with display: block is still a span, so choose elements for meaning first.

    Key ideas

    • Block by default: div, p, h1–h6, ul, section. Inline by default: span, a, strong, em, img.
    • inline-block flows like a word but accepts width, height and vertical margins. It's handy for buttons and badges.
    • display: flex and grid change how an element's children are laid out. The element itself acts like a block.
    • Changing display never changes what an element means. A span with display: block is still a span.

    Common mistakes

    • Setting width or height on a link or span and wondering why nothing happens.
    • Adding top margin to an inline element to push it down. It's ignored.
    • Putting a div inside a p. The browser closes the paragraph early and breaks your layout.
    • Mysterious small gaps between inline-block items. That's the space character between them in the HTML.
