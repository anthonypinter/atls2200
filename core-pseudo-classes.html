Pseudo-classes and Link States

Some styles should apply only some of the time: while a link is hovered, when a field is focused, to the first item in a list. Pseudo-classes select elements by their state or position, without adding a single class to your HTML.

You'll be able to

  • Select elements by position with :first-child, :last-child and :nth-child().
  • Style user-action states: :hover, :focus, :focus-visible and :active.
  • Style the five link states in the right order.
  • Turn a list of links into a navigation menu.

What is a pseudo-class?

A pseudo-class is a keyword after a selector, starting with one colon, that selects elements only when they're in a certain state. It acts as if you'd added a class to the element at exactly the right moment, without touching the HTML.

Basic pseudo-class example

To make the first paragraph of each article larger, you could add class="first" to it. But then if someone adds a new paragraph at the top, the class is on the wrong one. A pseudo-class always finds the right element:

article p:first-child {
  font-size: 120%;
  font-weight: bold;
}

:first-child and :last-child match an element that's the first or last child of its parent. :nth-child() takes a pattern: odd, even, a number, or a formula like 3n+1.

Watch out

p:first-child means "a p that is the first child of its parent", not "the first p". If an h2 comes first, no paragraph matches.

    User-action pseudo-classes

    These match only while the visitor is doing something:

    • :hover: while the pointer is over the element. Touch screens don't have it, so never hide anything important behind a hover.
    • :focus: when the element is selected for keyboard input, by clicking a field or pressing Tab.
    • :focus-visible: focus, but only when the browser thinks a visible ring helps, mainly keyboard use.
    • :active: while it's being pressed.

    Many people use a keyboard instead of a mouse, so give every :hover style a matching :focus-visible one, in the same rule:

    .btn:hover,
.btn:focus-visible {
  background: #1a2fa8;
}

    Forms add more: :disabled, :checked, :required, :invalid.

    Watch out

    Never remove the focus outline with outline: none unless you add a clear :focus-visible style in its place. Without it, keyboard users can't see where they are.

    Link states

    Links are the most-styled element with states. They have five:

    • :link: a link with an href that hasn't been visited.
    • :visited: one that's in the browser's history.
    • :hover, :focus and :active, as above.

    Default styles

    Browsers underline links, colour them blue (purple once visited, red while active), show a pointer cursor, and draw a focus outline. All of it can be changed. Keep links recognisable, though: if a link looks like normal text, nobody will click it.

    Styling links

    Write the state rules in this order, because they have the same specificity and later rules win. If :hover came before :visited, visited links would never show the hover style. Remember it as LoVe Fears HAte:

    a { }          /* every link */
a:link { }
a:visited { }
a:focus { }
a:hover { }
a:active { }

    For privacy, :visited can only change colours, not size or layout.

    Including icons on links

    A small icon can tell people where a link goes, like an arrow for links to other websites. Combine an attribute selector with the ::after pseudo-element (next lesson) to add one without touching the HTML:

    a[href^="http"]::after {
  content: " ↗";
}

    Styling links as buttons

    A navigation menu is just a list of links. Remove the bullets, put the items in a row, give each link padding so the whole box is clickable, and add hover and focus styles. Mark the current page with aria-current="page" in the HTML, and style that attribute.

    Key ideas

    • Pseudo-classes start with one colon and select by state or position.
    • :first-child means "first child of its parent", whatever its type.
    • Pair every :hover style with :focus-visible.
    • Link states in order: :link, :visited, :focus, :hover, :active.
    • A nav menu is a styled list of links; mark the current page with aria-current.

    Common mistakes

    • Removing the focus outline without a replacement.
    • Putting :hover before :visited, so visited links never react.
    • Expecting p:first-child to find the first paragraph after a heading.
    • Hiding information or menus behind :hover only.
    • Styling links so they look like plain text.
