Responsive Images

Images have a fixed size, but screens don't. Here's how to stop images from overflowing, crop them to fit a shape, and send phones a smaller file.

You'll be able to

  • Stop images from overflowing with max-width: 100% and height: auto.
  • Crop an image to fit a box with object-fit and object-position.
  • Offer several file sizes with srcset so phones download less.
Read

Images that fit every screen

An image has a fixed size in pixels, but your layout doesn't. Put a 1200px photo in a 360px-wide phone screen and it sticks out, pushing the whole page sideways. Two lines, which belong in nearly every stylesheet, fix that:

img {
  max-width: 100%;
  height: auto;
}

max-width: 100% lets an image shrink to fit its container but never stretch past its real size, and height: auto keeps its proportions. Keep the width and height attributes in your HTML too: the browser uses them to reserve the right space before the image arrives.

Sometimes an image must fill a box of a different shape, like a square profile photo cut from a wide picture. Setting both width and height would squash it. object-fit crops instead: cover fills the box and trims the edges, while contain shows the whole image and leaves empty space. object-position chooses which part stays in view.

Shrinking a big image with CSS still makes a phone download the whole big file. srcset lists several copies at different widths and lets the browser pick the smallest one that will look sharp:

<img src="arch-800.jpg"
     srcset="arch-400.jpg 400w, arch-800.jpg 800w, arch-1600.jpg 1600w"
     alt="The sandstone arch at the top of the trail">

The w after each file is its real width in pixels. The browser does the math, including the screen's pixel density.

Tip

When an image isn't full-width, add a sizes attribute so the browser knows how wide it will actually be. That's covered in Picture & Lazy Loading.

Send the right file with srcset

With srcset you list several copies of the same image at different widths. The browser downloads the smallest one that still looks sharp on the visitor's screen.

Most phones are 2x or 3x: each CSS pixel uses 2 or 3 real pixels across.

Make the images fit

A big photo breaks the layout and an avatar gets squashed. Fix both, and offer smaller files.

Key ideas

  • Put max-width: 100% and height: auto on images in nearly every stylesheet.
  • Keep the width and height attributes in the HTML. The browser uses them to reserve space before the image loads.
  • object-fit: cover fills the box and crops the edges. contain shows the whole image and leaves empty space.
  • Use object-position to keep the important part of the photo in view when it's cropped.

Common mistakes

  • Uploading a 4000px photo straight from a phone. It can be 5 MB for something shown 400px wide.
  • Setting both width and height in CSS without object-fit, which stretches the image.
  • Using width: 100% on a small image, which blows it up and makes it blurry.
  • Listing srcset widths that don't match the real files' widths.
