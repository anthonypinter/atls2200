Responsive Images

Images have a fixed size, but screens don't. Here's how to stop images from overflowing, crop them to fit a shape, and send phones a smaller file.

Part 1

Make it shrink

This photo is 800 × 500 pixels. Make the container narrower and see what each setting does.

The img tag has width="800" height="500" attributes, which you should always include.

Part 2

Fit it to a shape with object-fit

When an image has to fill a box of a different shape, like a square profile photo or a wide banner, object-fit decides whether to stretch, shrink or crop it.

Part 3

Send the right file with srcset

With srcset you list several copies of the same image at different widths. The browser downloads the smallest one that still looks sharp on the visitor's screen.

Most phones are 2x or 3x: each CSS pixel uses 2 or 3 real pixels across.

Key ideas

  • Put max-width: 100% and height: auto on images in nearly every stylesheet.
  • Keep the width and height attributes in the HTML. The browser uses them to reserve space before the image loads.
  • object-fit: cover fills the box and crops the edges. contain shows the whole image and leaves empty space.
  • Use object-position to keep the important part of the photo in view when it's cropped.

Common mistakes

  • Uploading a 4000px photo straight from a phone. It can be 5 MB for something shown 400px wide.
  • Setting both width and height in CSS without object-fit, which stretches the image.
  • Using width: 100% on a small image, which blows it up and makes it blurry.
  • Listing srcset widths that don't match the real files' widths.
