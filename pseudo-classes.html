    Key ideas

    • Pseudo-classes use one colon (:hover). Pseudo-elements like ::before use two.
    • Style :hover and :focus-visible together so keyboard users get the same feedback as mouse users.
    • Phones have no hover. Never hide something important behind :hover alone.
    • :nth-child(odd) and (even) are great for striped tables and lists.
    • For security, browsers only let :visited change colors, nothing else.

    Common mistakes

    • Removing focus outlines with outline: none and adding nothing back, so keyboard users get lost.
    • A space before the colon: a :hover means "any hovered element inside an a."
    • Expecting p:first-child to pick the first p. It picks a p only if it's the very first child of its parent.
    • Showing :invalid styles before the user has typed anything.
