Numbers and Strings

Most of what a program does is work with numbers and text: adding up distances, building messages, checking what someone typed. Here's the math, the operators, and the most useful things you can do with strings.

You'll be able to

  • Do arithmetic with JavaScript's operators, and predict the order they run in.
  • Use increment, assignment and comparison operators.
  • Build strings with quotes, template literals and concatenation, and convert between strings and numbers.
  • Find, extract and change parts of a string with its methods.

Types of numbers

In everyday code you'll use two kinds of number, whole numbers (integers, like 42) and decimals (floats, like 6.7), but JavaScript has just one type for both: Number. (There's also BigInt for enormous whole numbers, which you'll rarely need.)

Useful Number methods

toFixed() rounds a number to a set number of decimal places, for display. It returns a string.

Converting to number data types

Values that look like numbers can be strings, especially anything a visitor types into a form. Number() converts a string to a number; if it can't, you get NaN, "not a number".

Arithmetic operators

JavaScript has the usual operators, + - * /, plus two more: % (remainder) gives what's left over after dividing, so 7 % 2 is 1, and ** (exponent) raises to a power, so 5 ** 2 is 25.

Increment and decrement operators

++ adds one to a variable and -- takes one away. They're common in counters and loops. You can only use them on a variable, not a plain number.

Assignment operators

= assigns a value. Shortcut versions do the math and assign in one step: x += 4 means x = x + 4, and there's -=, *= and /= too.

Comparison operators

Comparisons give true or false:

  • === equal, and !== not equal. They check the type too, so 5 === "5" is false.
  • <, >, <=, >= for less and greater.

You'll see == and != in older code. They convert types before comparing, which gives surprises, so use the triple versions.

Declaring strings

A string is text in quotes. Without the quotes, JavaScript thinks the word is a variable name and gives an error.

Single quotes, double quotes, and backticks

You can use 'single', "double" or `backtick` quotes, as long as the start and end match. Pick one style for normal strings and stick with it. Backticks are special: they make a template literal.

Read

Embedding JavaScript

Inside a template literal, ${ } inserts the value of any variable or expression:

const name = "Chris";
const greeting = `Hello, ${name}`;

Concatenation using "+"

The older way is to join strings with +, called concatenation: "Hello, " + name. It works, but long ones get hard to read, with spaces easy to forget.

Including expressions in strings

${ } can hold any expression, not just a variable: `You scored ${(score / highestScore) * 100}%.`

Multiline strings

Template literals keep line breaks just as you type them. In a normal string, write \n for a new line.

Including quotes in strings

To put a quote inside a string, use the other kind around it ("It's steep"), or escape it with a backslash: 'It\'s steep'.

Numbers vs. strings

+ does two jobs. With two numbers it adds; if either side is a string, it joins them. Other operators like * and - always try to make numbers. Convert on purpose: Number("74") makes a number, and String(74) (or (74).toString()) makes a string.

Useful string methods

Strings as objects

Strings come with built-in properties and methods, which you use with a dot: text.length, text.toUpperCase(). Methods never change the original string: they return a new one. (Strings can't be changed at all; they're immutable.)

Finding the length of a string

text.length is the number of characters. It's a property, so no parentheses.

Retrieving a specific string character

Each character has an index, counted from 0: text[0] is the first, and text[text.length - 1] is the last.

Testing if a string contains a substring

includes("Arch"), startsWith("Royal") and endsWith("Trail") return true or false. They're case-sensitive.

Finding the position of a substring in a string

indexOf("Arch") returns where it starts, or -1 if it isn't there.

Extracting a substring from a string

slice(start, end) returns the characters from start up to, but not including, end. Leave out end to go to the end of the string.

Changing case

toLowerCase() and toUpperCase(). Handy for comparing what someone typed, whatever capitals they used.

Updating parts of a string

replace("old", "new") changes the first match; replaceAll() changes every match. Remember to store the result: text = text.replace(…).

Key ideas

  • One Number type for whole numbers and decimals. toFixed(2) rounds for display.
  • * and / before + and -; % is the remainder, ** a power.
  • ++, += and friends update a variable; === and !== compare value and type.
  • Template literals: `${value}`. + joins if either side is a string, so convert with Number().
  • String methods return new strings: includes, indexOf, slice, toLowerCase, replace.

Common mistakes

  • Adding a form value without Number(): "10" + 5 is "105".
  • Using == instead of ===.
  • Forgetting that slice's end index isn't included.
  • Calling a method and not storing the result, expecting the original string to change.
