What you've covered

This part was about the difference between a page that works and one that's finished: motion, forms, accessibility, tidy code, and the tools that catch mistakes before visitors do.

  • Transforms: Transforms move, rotate and scale without affecting layout.
  • Transitions & Animations: Transitions smooth changes between states; animations run keyframes; respect reduced motion.
  • Styling Forms: font: inherit, border-box inputs and a visible focus style fix most forms.
  • Accessibility Basics: Real buttons and labels, keyboard access, enough contrast, and never color alone.
  • Organizing CSS: Sections in a consistent order, names that describe purpose, variables, and low specificity.
  • Debugging with DevTools: The Styles pane shows which rules apply, which lost, and where each one lives.
  • Validating Your Code: Validators catch mistakes browsers silently repair. Fix from the top down.
  • Project Structure & Publishing: index.html at the top, lowercase file names, relative paths, then GitHub Pages.
