Fonts that travel with your page

Every computer has its own set of installed fonts, and they're not the same. A web font is downloaded along with your page, so every visitor sees the same type. The easiest source is Google Fonts: choose a font and the weights you need, and it gives you <link> tags to paste into your head, above your own stylesheet. Then use it like any other font:

body {
  font-family: "Source Sans 3", Arial, sans-serif;
}

You can also host the font files yourself, with an @font-face rule that names the font and points to a .woff2 file in your project.

A web font is a download, and downloads take time or fail. Until it arrives, the browser uses the next font in your font stack. Pick a fallback that's similar in width and feel, so the page doesn't jump around when the real font swaps in. font-display decides what visitors see in the meantime; swap, which shows the fallback right away and switches when the font arrives, is a good default.

Each weight and style is a separate file. Regular, italic, bold and bold italic are four downloads. Two families and three or four weights in total is plenty for most sites.

Watch out

If you use font-weight: 700 but only downloaded weight 400, the browser fakes a bold by smearing the regular letters. And a misspelled font name fails silently: CSS just falls back, with no error. Check DevTools to see which font actually rendered.

The easy way: Google Fonts
  1. Find a font at fonts.google.com and choose the weights you need.
  2. Copy the <link> tags it gives you into your page's <head>, above your own stylesheet.
  3. Use the font in CSS with font-family, followed by fallbacks.
Self-hosting with @font-face
  1. Put the .woff2 files in a fonts/ folder in your project.
  2. Add an @font-face rule naming the font and pointing to the file.
  3. Use that name in font-family like any other font.

Key ideas

  • Put font names with spaces in quotes: font-family: "Source Sans 3", sans-serif;
  • End every font list with a generic family: serif, sans-serif or monospace.
  • font-display: swap is a good default. Text shows right away and switches when the font arrives.
  • Two families and three or four weights is plenty for most sites.

Common mistakes

  • Using a font name in CSS without the <link> or @font-face that loads it. It only works on computers that happen to have it installed.
  • Asking for font-weight: 700 when only 400 was downloaded, so the browser fakes a blurry bold.
  • Misspelling the font name. CSS silently falls back with no error.
  • Fancy script fonts for body text, which are hard to read at small sizes.
