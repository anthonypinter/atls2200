Document Structure

Every HTML page starts with the same skeleton. Click any line to learn what it does, then remove it to see what breaks.

On a phone
    How it nests
    <html>
    <head> info about the page, not shown
    meta · title · link
    <body> everything people see
    h1 · p · img · nav · …

    Key ideas

    • <head> holds information about the page. <body> holds what visitors see.
    • Every element you open, you close, and tags close in the reverse order they opened.
    • Indent nested elements so you can see the structure at a glance.
    • Save the file as index.html for the main page of a site. Servers look for that name first.

    Common mistakes

    • Putting visible content like <h1> inside <head>.
    • Having two <body> elements, or content after </html>.
    • Leaving out the viewport meta tag, so phones show a tiny zoomed-out page.
    • Linking a stylesheet with the wrong path, like href="style.css" when the file is in a css/ folder.
