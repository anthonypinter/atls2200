What you've covered

This part was about arranging boxes. Each tool has a job: Flexbox for rows, Grid for rows and columns, floats for wrapping text, and positioning for things that overlap.

  • Flexbox: display: flex on the parent lines its children up in a row, with justify-content and align-items to space and align them.
  • CSS Grid: Grid defines columns and rows, fr shares out space, and items can span several cells.
  • Flexbox vs Grid: Flexbox for one direction sized by content, Grid when columns must line up.
  • Floats: Floats wrap text around an image, clear starts below them, and flow-root contains them.
  • Positioning: absolute places an element inside its nearest positioned ancestor; sticky and fixed stay put while scrolling.
